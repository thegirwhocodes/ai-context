# Education for Equality — Codebase Deep Research

## The shape of the repo

The project root is a **hybrid research-vault + monorepo**. Most of the 11 numbered folders (`1. The Problem` … `10. Bakame`) are research/strategy documents, not code. The actual software lives in two independently-versioned git repos:

| Repo | Stack | Runs on | Role |
|---|---|---|---|
| [curriculum-app/](curriculum-app/) | Next.js 16, React 19, TS, Tailwind v4 | **Vercel** (eduforequality.org) | Web app + curriculum + **the serverless voice pipeline** (AT + Twilio webhooks) |
| [sabi-server/](sabi-server/) | FastAPI / Python | **Hetzner GPU** (136.243.8.51) | Self-hosted STT/TTS/LLM + its own AT/Twilio/Asterisk voice pipeline |

The crucial architectural fact: **there are two complete, parallel voice pipelines** that have drifted apart. The Vercel one is what's actually answering phone calls today; the Hetzner one supplies the GPU models (Whisper, Chatterbox) and contains a more advanced (streaming) but currently-secondary call path.

---

## Pipeline 1 — curriculum-app (the live one)

**Two telephony paths**, sharing the same brain:

- **Africa's Talking** (Nigerian number, XML): [at/incoming](curriculum-app/app/api/sabi/at/incoming/route.ts) → [at/recording](curriculum-app/app/api/sabi/at/recording/route.ts), helpers in [at-xml.ts](curriculum-app/lib/voice/at-xml.ts). STT = Groq Whisper, TTS = ElevenLabs→Chatterbox→YarnGPT→AT `<Say>`.
- **Twilio** (US number, TwiML): [voice/incoming](curriculum-app/app/api/sabi/voice/incoming/route.ts) → [voice/respond](curriculum-app/app/api/sabi/voice/respond/route.ts). STT = Twilio's built-in `<Gather>` speech, TTS = Twilio Polly.

The shared brain is [sabi-shared.ts](curriculum-app/lib/voice/sabi-shared.ts) — the single most important file. It holds:
- `SABI_CORE_PROMPT` — personality + the **"Naira-first, abstract-second"** pedagogy + 5-7 min lesson structure.
- `MODULE_CURRICULUM` — 7 numeracy modules (0 diagnostic → 6 word problems) as fallback text.
- `callSabiVoiceFast()` — the latency path: **Cerebras llama-3.3-70b → Groq → Claude Haiku** fallback chain. All voice routes use this.
- `getStudentMemory()` / `findOrCreateStudentByPhone()` — Supabase-backed student memory + spaced repetition.

Call state is persisted in Supabase (`sabi_active_calls`), not memory, because Vercel functions are stateless — [call-state.ts](curriculum-app/lib/voice/call-state.ts). RAG curriculum injection is in [retrieval.ts](curriculum-app/lib/rag/retrieval.ts) (pgvector via `search_curriculum` RPC, with graceful fallback to the hardcoded module text).

**Current live status** (from session 262aa5fe, Jun 9 22:00 UTC): the **AT Nigerian number (+2342017001459) is blocked** — AT's routing cache is pinned to a dead localtunnel URL and needs AT support to clear. The working demo right now is the **Twilio US number +17153122345**, freshly repointed from ElevenLabs ConvAI to `/api/sabi/voice/incoming`, verified end-to-end with a 3-turn synthetic conversation. It uses Polly.Amy (not the Bukola/Naomi voice yet).

## Pipeline 2 — sabi-server (Hetzner GPU)

[main.py](sabi-server/main.py) is a FastAPI app loading models on startup: `SpeechToText` (Groq Whisper → local faster-whisper large-v3 fallback, [stt.py](sabi-server/stt.py)), `TextToSpeech`, `SabiLLM` ([llm.py](sabi-server/llm.py), same Cerebras→Claude→Groq→Ollama chain), plus an **Asterisk FastAGI server for flash-callback** (child rings, hangs up, server calls back so the child pays ₦0). TTS here adds **emotion-aware Chatterbox** — `detect_exaggeration()` maps `[laugh]/[sigh]` tags to 0.35–0.75 expressiveness levels. It also has a `/process-turn` one-shot pipeline and streaming LLM (`generate_streaming`, sentence-by-sentence) that the Vercel path doesn't use.

**1. The `callBackUrl` regression is back (the one memory explicitly warned about).**
Memory from Jun 8 says: *"DO NOT remove callBackUrl again."* Commit `15e5167` fixed the AT `<Record>` attribute to `callBackUrl` (capital B, U) — AT silently ignores the lowercase form, causing "greeting then silence." But the auto-save commit **`c530750` (Jun 9 14:55) reverted it to lowercase `callbackUrl`** while flipping `trimSilence`. The live Vercel AT XML at [at-xml.ts:44](curriculum-app/lib/voice/at-xml.ts#L44) and [:78](curriculum-app/lib/voice/at-xml.ts#L78) is currently **wrong again**. (sabi-server [voice.py](sabi-server/voice.py) is still correct.) This doesn't break the Twilio demo, but it will re-break the AT path the moment AT support unblocks the number. The culprit is `auto_deploy.py` auto-committing in-progress edits.

**2. Two pipelines drifting.** The Vercel and Hetzner code duplicate AT/Twilio logic with diverging behavior (TTS order, prompts, casing). Bug fixes have to be applied twice and one side keeps lagging.

**3. Inconsistent STT confidence handling.** AT recording route deliberately ignores confidence; Twilio respond gates `<0.3`; sabi-server `/process-turn` gates `<0.5` — but Groq STT returns a **hardcoded 0.82** ([stt.py:107](sabi-server/stt.py#L107)), so that gate never meaningfully fires.

**4. Security gap.** Twilio routes verify signatures (`isTwilioRequest`); **AT webhooks have no signature verification** — a credit-burn risk at scale. sabi-server's `APIKeyMiddleware` also leaves all `/voice/*` open by design.

**5. Dead/unused code.** `answer_matcher.py` (server) and parts of `answer-matcher.ts` are unused — the LLM judges answers directly (only `normalizeNumberMishears` is wired in, AT path only).

**6. Latency.** Memory notes the AT path was ~5-6s/turn because it historically used slow Claude+sequential TTS; the code now routes through `callSabiVoiceFast` (Cerebras), so that's largely addressed — but streaming TTS (which exists only in sabi-server) isn't on the Vercel path.

There's also one trivial uncommitted change in [at/incoming/route.ts](curriculum-app/app/api/sabi/at/incoming/route.ts) (a `URLSearchParams` construction fix) and no automated test suite beyond `load_test.py`.
