## Jupyter Notebook Environment and Access

The Workbench Dashboard allows researchers to create large datasets with access to a Jupyter Notebook environment where researchers can apply programmatic methods in Python or R to interrogate their chosen content. TDM Studio has two components: Visualizations, which is an entirely browser-based, point-and-click interface with data visualizations, and Workbench, for researchers and their teams coding with R or Python in Jupyter notebooks.

## Uploading and Downloading with Jupyter Notebooks

Instructions on how to upload local files to your Jupyter Notebook in TDM Studio are available through the platform's resources. You can upload scripts or any type of file to the Jupyter environment by following the steps in the Upload instructions.ipynb file in the Jupyter notebook. Additionally, you can upload the entire .ipynb file into the environment through Workspace's upload functionality, or you can upload this notebook directly into the Workbench environment by using the My Files features on the taskbar at top of screen and then uploading into the Jupyter Notebook environment via the Upload button.

## Data Export Limitations

You can export any derived data, as well as scripts, tables and visualizations. Due to copyright restrictions, you cannot export full text or any consumptive information that could be used to reconstruct the full text. The current export limit is 15 MB per week. To export your dataset (collection of texts) as a .csv, you must use a noise function to alter the Full Text data - ProQuest does not permit exporting complete, unaltered full texts.
