## USSD Phase 2 Specification (GSM 03.90)

USSD Phase 2 is specified in GSM 03.90, and it supports both mobile-initiated as well as network-initiated operations.

## Display Text During Voice Call

According to the GSM 03.90 specification, when the Mobile Station is in a state where it can handle the operation, for a USSD request, the MS shall display the text provided and await user input. If the user enters a response, the MS shall return the response to the MSC, maintaining the transaction.

## Call-Related USSD Operations

An important capability of USSD is that the MS may initiate a USSD Operation either during a call or out of call. This means with USSD, messages can even be initiated during calls, allowing simultaneous voice and data communication.

## How It Works

The mechanism allows the Mobile Station user and a PLMN operator defined application to communicate in a way which is transparent to the MS and to intermediate network entities. When a USSD message is received, text is displayed to the user, who can respond, and the session is maintained throughout the exchange.
