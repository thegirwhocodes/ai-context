## Key Projects with Open Source Code and Models

CorrNet released CorrNet+, an unified model with superior performance on both continuous sign language recognition and sign language translation tasks by using only RGB inputs, with a demo for continuous sign language recognition supporting multi-images and video inputs released in January 2025.

The "Towards Online Continuous Sign Language Recognition and Translation" paper (EMNLP 2024) provides code and models available at https://github.com/FangyunWei/SLRT.

## Recent Pretrained Model Approaches

SignVLM is a pretrained large vision model proposed for sign language recognition to address the issue of lacking annotated datasets.

Uni-Sign is a unified sign language understanding model where robust SLU capabilities integrated during large-scale pre-training are transferred to downstream tasks including CSLR and SLT.

ConSignformer is a multi-modal pipelined framework adapted from the Conformer model for CSLR, with unsupervised pretraining performed on Indian Sign Language pose data, creating a sign language agnostic Conformer model practicable for diverse sign languages.

## Available Open Source Resources

Recent 2024-2025 models with code availability include works from EMNLP 2024 on online CSLR/SLT and KD-MSLRT (AAAI 2025) for lightweight sign language recognition.
