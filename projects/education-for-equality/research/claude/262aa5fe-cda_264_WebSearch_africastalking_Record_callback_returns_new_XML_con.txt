## Record Callback with XML Response

Build voice XML when callback URL receives a POST from the voice API. Actions can be chained to create an XML string.

### PHP Example

In PHP, you can use `$voiceActions = $voice->messageBuilder(); $xmlresponse = $voiceActions ->getDigits($options) ->say($text) ->record() ->build();` to chain actions together for recording.

### Key Recording Parameters

The search results reference recording-related options including:
- trimSilence: Boolean - Specifies whether you want to remove the initial and final parts of a recording where user was silent
- playBeep: Boolean - Specifies whether the API should play a beep when recording starts

### Voice Callbacks for Continued Conversation

For any call handled, whether made to the virtual number or from the virtual number the API gateway will invoke your voice callback. When handling a call mapped to your number, the callback_url is invoked with POST params sent to your API, and you must handle a POST request on your callback_url.
