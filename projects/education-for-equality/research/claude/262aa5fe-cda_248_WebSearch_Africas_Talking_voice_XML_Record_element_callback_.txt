## Record Element Callback Attribute

The `callbackUrl` is a URL to forward the results of the Recording action. This attribute is used to specify where Africa's Talking should send the recording data after the recording completes.

## Record Element Attributes

The Record element supports the following attributes:

- **trimSilence**: Boolean - Specifies whether you want to remove the initial and final parts of a recording where user was silent
- **playBeep**: Boolean - Specifies whether the API should play a beep when recording starts
- **callbackUrl**: URL to forward the results of the Recording action
