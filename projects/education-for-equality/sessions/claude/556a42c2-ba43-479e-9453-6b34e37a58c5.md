Here's exactly what that button does, mechanically — no magic:

## The move itself
1. You select rows and click **Move to OneDrive ☁︎**.
2. It finds your OneDrive folder — on your Mac that's `~/Library/CloudStorage/OneDrive-wesleyan.edu`. (This is a real folder; the modern OneDrive app puts your synced files under `~/Library/CloudStorage/`, not the old `~/OneDrive`.)
3. It makes a subfolder there called **`Downloads Archive`** (once).
4. For each selected file it does a **filesystem move** (`mv`) from `~/Downloads` into that folder. If a file with the same name already exists there, it appends ` 2`, ` 3`, etc. so nothing is overwritten.
5. The file **disappears from your Downloads list** and the app re-scans.

That's it — it's `FileManager.moveItem`, the same thing dragging a file in Finder does. No upload code, no OneDrive API. The move is instant even for big files (same disk).

## What OneDrive does next (this is the part the app doesn't control)
Because the destination is inside OneDrive's synced folder, the **OneDrive app** notices the new files and starts **uploading them to the cloud** in the background. You'll see the little sync arrows on them in Finder, then a green check when uploaded.

## ⚠️ The important caveat: local disk space
A plain move **does not immediately free up local space**. The file is still on your Mac — it just lives in the OneDrive folder now instead of Downloads. After OneDrive finishes uploading, the bytes are still stored locally unless you tell OneDrive to offload them.

To actually reclaim the disk space, you (or OneDrive) need **Files On-Demand**:
- **Manual, per-file:** in Finder, right-click the file in the OneDrive folder → **"Free Up Space."** It keeps a cloud-only placeholder (0 bytes local) and re-downloads on demand when you open it.
- **Automatic:** OneDrive Settings → often has an option to free up space for files you haven't opened recently.

So the honest summary: **Move to OneDrive = "get it out of Downloads and into the cloud backup."** It frees space *after* OneDrive uploads and you (or its auto-setting) free it up. If your goal is purely "reclaim disk now," **Move to Trash** is the immediate win; OneDrive is the "keep it but off my main folder" option.
