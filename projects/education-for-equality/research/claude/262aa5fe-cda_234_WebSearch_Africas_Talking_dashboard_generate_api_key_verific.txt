## Key Findings:

**API Key Generation Process:**
To generate an API key, click your profile icon and go to Settings, navigate to the "API Key" section, click "Generate New API Key", enter your account password when prompted, and a confirmation email will be sent. Click the button in the email to generate your key.

**Verification Code Requirement:**
The search results confirm that a confirmation email will be sent and you need to click the button in the email to generate your key, which suggests a verification step is part of the process.

**Production vs. Sandbox:**
After logging in, you will see two sections: Sandbox and Teams. Sandbox is for development and testing purposes with a test app and free credits, while Teams is for real/live production use where you can manage real services and billing.

**Important Note About Production Keys:**
The connector currently only works with production ready applications, so DO NOT use the default sandbox application's API key.

If you're experiencing issues with the verification code not showing for production API key generation, this may be related to the dashboard UI or email delivery issues. The search results suggest contacting info@africastalking.com for further enquiries.
