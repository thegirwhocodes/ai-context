## SelfControl Helper Tool and Firewall Configuration

The SelfControl helper command-line tool is located inside the SelfControl.app bundle at SelfControl.app/Contents/MacOS/org.eyebeam.SelfControl, and when a block is started, the command-line tool is copied to /Library/PrivilegedHelperTools/org.eyebeam.SelfControl.

## Firewall Rules with pfctl Anchors

eyebeam.org is the name under which SelfControl runs and it has created and configured a pfctl anchor. Anchors contain a set of rules that can control packet forwarding.

When SelfControl is active, there is roughly one firewall rule per blocked domain under the org.eyebeam anchor. The root pf config file includes a load anchor "org.eyebeam" from "/etc/pf.anchors/org.eyebeam" entry.

The firewall rules system allows SelfControl to block access to specific domains at the network level using macOS's built-in packet filter (pf) framework, with the anchor mechanism providing organization and management of these blocking rules.
