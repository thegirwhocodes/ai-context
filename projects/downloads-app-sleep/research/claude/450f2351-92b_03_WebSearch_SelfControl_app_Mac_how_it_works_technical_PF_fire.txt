## How SelfControl Works

SelfControl is a standalone macOS app that blocks access to websites you specify by adding domains to a blocklist, setting a timer (up to 24 hours), and hitting start.

## Technical Implementation

The blocking works at the macOS packet filter firewall level (/etc/pf.conf), where SelfControl writes rules that drop DNS requests and TCP connections to blocked domains at the OS level.

## Irreversible Timer

Once the timer starts, the block cannot be undone. The firewall rules persist at the OS level until the timer expires—deleting the app, restarting your Mac, or reinstalling macOS will not remove the block.

## Scope of Blocking

Because SelfControl modifies the macOS firewall, it blocks domains across every browser and every app, with blocked sites not redirecting to a warning page but the request being killed before it starts.

## Blocklist Configuration

There are no category presets like "block all social media"—if you want to block 15 sites, you're adding 15 domains manually, though you can save your blocklist for reuse. The app has two modes: Blocklist mode where only specified websites are blocked, and Allowlist mode where the entire Internet is blocked except websites added to the Allowlist.

## Additional Technical Details

The source code is on GitHub, so anyone can audit it. SelfControl is a free and open-source application for macOS.
