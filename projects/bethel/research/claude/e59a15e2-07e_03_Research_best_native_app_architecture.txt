**The key finding: Every premium Bible, journaling, writing, and AI chat app is built natively.**

- **Glorify**: Fully native -- Swift/SwiftUI (iOS), Kotlin (Android), Node.js/MongoDB backend. Built by Tapptitude specifically for premium polish.
- **YouVersion**: Native SwiftUI + Jetpack Compose with Kotlin Multiplatform for shared business logic (networking, caching, auth). The "best of both worlds" approach.
- **Bear Notes**: Fully native Swift (AppKit/UIKit), Apple-only. Small team (~5-8), Apple Design Award winner.
- **Day One**: Native Swift. Acquired by Automattic.
- **ChatGPT & Claude mobile**: Both appear to be native (deep platform integration, job postings, performance characteristics).
- **Dreamnl**: Likely cross-platform (solo dev shipping iOS+Android simultaneously) -- but also not in the "premium" tier.

**React Native/Expo in 2026 is genuinely good** -- the New Architecture (Fabric, JSI, TurboModules) is production-ready, Reanimated 3 delivers 60fps animations, Skia enables GPU rendering, and Expo now supports SwiftUI primitives directly. Glassmorphism, offline SQLite, and even on-device ML (via ExecuTorch/CoreML backend) are all possible.

**But the honest tradeoffs for Bethel's specific needs:**
1. **Text rendering** -- React Native cannot match native TextKit 2 for e-reader quality typography (ligatures, hyphenation, widows/orphans control)
2. **Rich text editing** -- RN's weakest area; no equivalent to native text editing stacks that Bear and Day One use
3. **The "last 5%" of polish** -- possible but requires significantly more effort than native

**The recommendation**: If Bethel's vision is truly premium (Glorify-level), the most aligned path is **iOS-first in Swift/SwiftUI, then Android via Kotlin with shared logic via KMP** (the YouVersion model). If budget forces cross-platform, React Native/Expo is viable but will require constant polish work and custom native modules for the reader and editor.
