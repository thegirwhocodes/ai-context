## Installation and Basic Setup

The Cerebras Inference library is available for download and installation through the Python Package Index (PyPI), and you can install it via pip.

## Basic Integration Example

To use the SDK, you import from `cerebras.cloud.sdk import Cerebras`, create a client with your API key from the environment, and then call `client.chat.completions.create()` with your messages and model. Here's a simple example:

```python
import os
from cerebras.cloud.sdk import Cerebras

client = Cerebras(
    api_key=[REDACTED:sensitive-label]("CEREBRAS_API_KEY"),
)

chat_completion = client.chat.completions.create(
    messages=[
        {
            "role": "user",
            "content": "Why is fast inference important?",
        }
    ],
    model="llama3.1-8b",
)
print(chat_completion)
```

## Advanced Features

The SDK also supports completions with prompts and max_tokens parameters, and async operations using AsyncCerebras with streaming responses.

## OpenAI Compatibility

If your application uses the OpenAI Python SDK, you can switch to Cerebras by changing the base URL and API key with no other code changes required.
