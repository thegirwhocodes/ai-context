## USSD Push Definition

Network-initiated (NI) USSD, also known as USSD Push or Mobile Terminating USSD, is when the application starts the USSD session on the handset. This contrasts with mobile-initiated (MI) USSD Pull, where the end-user initiates the USSD session on their handset.

## USSD Gateway Services and API Integration

A USSD gateway is a service that enables communication between your application and the mobile network provider's USSD platform. Your application must use the service provider's APIs to communicate with the USSD gateway, which facilitates message exchanges between your application and the USSD gateway, enabling smooth communication.

## Nigeria USSD Providers

All telcos - MTN, Glo, Airtel & Etisalat provide USSD gateways, and if you're looking for a USSD short code service, you can get it from the telcos or work with VAS service providers.

Several third-party USSD gateway providers offer API services for Nigeria, including:
- **Infotekps** - Offers dedicated and shared USSD solutions with HTTP API connections between their USSD gateway and your application.
- **Flutterwave** - Offers USSD payments for Nigerian Naira (NGN) collections.
- **Beem**, **Africa's Talking**, **Telerivet**, and **Qrios** also provide USSD API gateway services
