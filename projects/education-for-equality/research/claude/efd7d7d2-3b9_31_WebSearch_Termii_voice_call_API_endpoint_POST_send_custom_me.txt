## Voice Call API Endpoint

The endpoint is `https://BASE_URL/api/sms/otp/call` with POST as the request type.

## Request Body Example

The JSON payload should include the following fields:

```json
{
  "api_key": "Your API key",
  "phone_number": "2349800000000",
  "code": 55675
}
```

## Important Note

The voice call API enables you to send messages through the voice channel to a phone number. Only one-time-passwords (OTP) are allowed for now and these OTPs cannot be verified using the Verify Token API.

The required parameters are:
- **api_key**: Your Termii API key
- **phone_number**: The recipient's phone number
- **code**: The OTP code to be delivered via voice call
