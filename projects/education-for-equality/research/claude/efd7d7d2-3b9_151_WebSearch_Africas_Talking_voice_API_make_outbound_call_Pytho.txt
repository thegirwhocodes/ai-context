## Installation

You can install the package with `pip3 install africastalking` for Python 3.8.x or higher.

## Basic Setup

Initialize the SDK by calling africastalking.initialize(username, api_key). For sandbox, the app username is ALWAYS sandbox, though you should use your actual username and API key for production.

## Voice API Features

You can build a virtual call centre by automating inbound and outbound calls hence streamlining your customers' call experiences. You can record your call sessions into an MP3 file that you can retrieve and play later, which will prove useful when conducting surveys or ensuring quality of service in call centres.

## Important Note About Sandbox Mode

Africa's Talking Voice API doesn't work in sandbox mode. Every call you make during development will be a real call that costs real money and rings a real phone.
