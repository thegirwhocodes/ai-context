## Overview

Antigravity supports the Model Context Protocol (MCP), a standard that allows the editor to securely connect to your local tools, databases, and external services.

## Key Features

With Model Context Protocol (MCP) servers powered by MCP Toolbox for Databases now available within Antigravity, you can securely connect your AI agents to services like AlloyDB for PostgreSQL, BigQuery, Spanner, Cloud SQL, Looker and others within Google's Data Cloud.

Model Context Protocol (MCP) standardizes how large language models (LLMs) and AI applications or agents connect to external data sources.

## Server Types

Antigravity supports both:
- Local MCP servers that typically run on your local machine and use the standard input and output streams (stdio) for communication
- Remote MCP servers that run on the service's infrastructure and offer an HTTP endpoint to AI applications for communication

## Getting Started

Open the MCP Store panel within the "..." dropdown at the top of the editor's side panel and select any of the supported servers from the list and click Install. You can also modify the mcp_config.json configuration file located at ~/.gemini/antigravity/mcp_config.json, which has a single mcpServers object where you define each server you want to connect to.

## Known Limitations

Antigravity doesn't support the MCP OAuth specifications, which prevents you from using a client ID and secret, so you can't authenticate to the MCP server.
