## Overview

Google Calendar offers a remote Model Context Protocol (MCP) server that allows AI agents to securely interact with Google Calendar data. By configuring the Google Calendar MCP server, you enable AI applications like Gemini CLI, Claude, or IDEs to perform actions in Google Calendar.

## Remote MCP Server URL

The remote MCP server URL is https://calendarmcp.googleapis.com/mcp/v1

## Configuration for Cursor

There are two ways to add an MCP server to Cursor. The most common way is to add the server globally in the ~/.cursor/mcp.json file so that it is available in all of your projects.

When you add a global MCP server, the ~/.cursor/mcp.json file will be opened and you can add your server configuration.

## Capabilities

The Google Calendar MCP server provides a standardized way for AI agents to read data like list calendars, retrieve events, and check availability, and take action such as create, update, and delete events.

## Authentication

The Google Calendar remote MCP server uses OAuth 2.0. In Advanced settings, you need to enter your OAuth client ID and OAuth client secret.

For more detailed documentation and setup instructions, you can refer to the official Google Calendar MCP documentation at the Google Developers site.
