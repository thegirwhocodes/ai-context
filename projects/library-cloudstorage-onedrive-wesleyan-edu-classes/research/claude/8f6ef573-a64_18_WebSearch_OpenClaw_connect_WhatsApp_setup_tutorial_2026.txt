## OpenClaw WhatsApp Setup Overview

OpenClaw is an open-source personal AI assistant that runs directly on your devices and lets you build a personal AI assistant that integrates with popular platforms like WhatsApp, Telegram, Slack, Discord, Signal, and iMessage.

## Basic Setup Steps

1. **Configure WhatsApp Channel**: Configure WhatsApp in ~/.openclaw/openclaw.json and run openclaw channels login to scan the QR code (Linked Devices).

2. **QR Code Connection**: You will be shown a QR code to connect the agent. Open WhatsApp, select the QR code option, go to the "SCAN CODE" section, and frame the QR code with your camera.

3. **Set Up Your Gateway**: The only step left is to install and run the OpenClaw gateway so you can interact with your AI assistant directly on WhatsApp. The OpenClaw Gateway is the always-on process that manages the Baileys/Telegram connection and acts as the control and event plane for OpenClaw.

## Phone Number Requirements

WhatsApp requires a real mobile number for verification. VoIP and virtual numbers are usually blocked. The ideal setup is a spare/old Android phone + eSIM, left on Wi-Fi and power, and linked via QR.

## Testing Your Setup

If you open WhatsApp and check the chat with yourself, you should see the test message delivered.

The official OpenClaw documentation and several recent tutorial sources provide additional configuration options for controlling who can message your bot and managing security settings.
