## Model Architecture

The SignVLM architecture includes a trainable Transformer decoder, trainable local temporal modules and pre-trained models, with a fixed image backbone using CLIP. The model explores the capability of the contrastive language-image pre-training (CLIP) model for sign language recognition, using CLIP to extract spatial features from sign video frames while a Transformer decoder is used for temporal learning.

## Datasets and Evaluation

The proposed model has been evaluated on four different sign languages using the KArSL, WLASL, LSA64, and AUSTL datasets.
