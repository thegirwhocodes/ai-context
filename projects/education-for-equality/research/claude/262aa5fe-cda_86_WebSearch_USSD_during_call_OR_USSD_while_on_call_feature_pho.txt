## USSD During Calls - Key Findings

USSD messages can be initiated during calls, allowing simultaneous voice and data communication. This is a distinctive feature of USSD technology on GSM networks.

### Technical Details

USSD is a messaging service used in Global System for Mobile Communications (GSM) networks similar to SMS, where it sends data utilizing the signaling channel. This is what enables the simultaneous operation with voice calls.

Both USSD Phase 1 and 2 services can happen simultaneously with a phone call (Call Related USSD Services) or without voice connection (Call Independent USSD Services).

### How It Works

The USSD gateway has an interface with the Mobile Switching Center (MSC) over the Signaling System #7 (SS7). A real-time session is initiated between the mobile user and the USSD application platform when the service is invoked, allowing data to be sent back and forth.

### Device Support

USSD works on almost all GSM mobile phones (from old handsets to new smartphones), making it particularly useful for feature phones and basic mobile devices that may not support other data services.

This capability makes USSD especially valuable for applications like balance checking, prepaid recharges, and mobile banking that users may need to access while already on a call.
