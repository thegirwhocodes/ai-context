## Voice Recording Callback Information

You need to register a callback URL that is valid and accessible, allowing Africa's Talking to send requests to it. Upon call termination, a final notification is sent to your callback URL, furnishing additional details like call cost and duration.

## Record Action in Voice API

When the callback URL receives a POST from the voice API, you build voice XML by chaining actions together to create an XML string. The record action can be included in your voice XML response.

## Recording Options

Available recording parameters include trimSilence (Boolean - to remove initial and final parts where user was silent) and playBeep (Boolean - to play a beep when recording starts).

## POST Callback Security

Africa's Talking only allows access to POST requests with the correct username and API key combination, so your request is secure as long as you haven't exposed your API key.
