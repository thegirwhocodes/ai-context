## eCFR API and XML Access

eCFR data originates with files used to produce print and PDF editions, and during publication these are transformed into bulk XML files made available by the Government Publishing Office (GPO), which are then processed into smaller units tracked over time to create the point-in-time features of the eCFR.

## API Versioner Endpoint

One of the search results shows an example of the API versioner endpoint structure: `https://www.ecfr.gov/api/versioner/v1/full/[date]/title-[number].xml`. This endpoint format allows you to request specific titles at particular dates in XML format.

## Bulk XML Download

The XML data can be downloaded daily at http://www.gpo.gov/fdsys/bulkdata/ECFR. Bulk data downloads of Code of Federal Regulations files in XML format are available from 1996 to the present, by year, title, and volume.

## Important Notes

The XML-structured files offered for bulk download are not part of the official on-line format of the CFR or the Federal Register.

For more details on API endpoints and specific parameters, you can visit the official eCFR Interactive Documentation, detailing the different endpoints and possible parameters at https://www.ecfr.gov/readers-aids/ecfr-developer-resources.

Regarding Title 32 (Department of Defense) and Joint Travel Regulations specifically, you would use the same API and bulk download mechanisms with the title-32 identifier.
