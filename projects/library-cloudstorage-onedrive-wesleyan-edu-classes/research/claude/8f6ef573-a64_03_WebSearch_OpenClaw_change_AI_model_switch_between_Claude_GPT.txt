## Switching Models in OpenClaw

### Mid-Session Model Switching
You can switch models mid-session with the `/model` command (e.g., `/model opus` or `/model haimaker/llama-3.3-70b`). The aliases in the config - opus, sonnet, flash, ds - are what you type after `/model`.

### Configuration File Setup
The config file goes in your home directory: ~/.openclaw/openclaw.json. If you installed the older Clawdbot package via npm, check ~/.clawdbot/clawdbot.json instead.

### Setting Default Models
You can configure the default model with: `{ agents: { defaults: { model: { primary: "anthropic/claude-sonnet-4-20250514" } } } }`

### Model Tiering Strategy
The fix for cost optimization is model tiering - different models for different tasks based on what each one needs. Edit your config file in the home directory and restart to apply changes.

### Ollama Configuration
To replace the configuration with an Ollama based configuration, you give it the provider with an endpoint and specify your model. As you change the config file, restart the gateway with systemctl.

### OpenRouter Integration
OpenClaw has built-in support for OpenRouter - you don't need to configure models.providers, just set your API key and reference models with the openrouter/<author>/<slug> format.

### Supported Providers
OpenClaw supports a dozen providers including Anthropic, OpenAI, Google, and open-source models through haimaker.ai.
