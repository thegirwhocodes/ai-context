# Project Perception - AI Expo Hackathon 2025

## What They Built

Project Perception is "a video analysis platform designed for interrogation and surveillance scenarios" that uses computer vision and AI to detect emotions, blinks, and objects in video footage, plus includes a chatbot assistant for querying results.

## Team Members

The team consisted of Joshua John, Yue (Michelle) Lei, and Yingquan Li.

## Tech Stack

The project uses Python 3.12, Flask, OpenCV, DeepFace, YOLOv8, PyTorch, and the OpenAI API for the backend, with HTML5, CSS3, and vanilla JavaScript for the frontend.

## Key Features

- Real-time emotion detection via webcam
- Video upload and analysis capabilities
- YOLOv8-based object recognition
- Playback and history review
- Chatbot assistant for result queries
