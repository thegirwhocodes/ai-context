## Speech Recognition and Hints

Hints provide a comma-separated set of words that instruct the speech recognition engine about what input is expected, which improves accuracy. You can provide hints up to 500 words to boost accuracy, and providing good hints makes matching very accurate.

## Input Methods: Speech vs. DTMF

The input attribute allows you to specify which inputs Twilio should accept—dtmf, speech, or dtmf speech. If you set dtmf speech for input, the first detected input will take precedence, and if speech is detected first, finishOnKey will be ignored.

## Handling Expected Numbers

You can set the number of digits you expect from your caller by including numDigits in <Gather>. For numeric inputs specifically, if you're expecting a "short utterance" as input, you should use speechTimeout with value auto—examples include collecting numbers, addresses or short commands.

## Best Practices for Voice Agents

Provide DTMF as an alternative input method when speech recognition fails, allowing users to input responses using the keypad if needed. Additionally, to minimize outside noise interference, use the phone's handset mode rather than speakerphone, and noise-canceling microphones and acoustic echo cancellation can significantly enhance recognition accuracy.

## Speech Recognition Parameters

When using speech as input, Twilio includes a Confidence parameter value along with the recognized speech result—Confidence contains a confidence score between 0.0 and 1.0.
