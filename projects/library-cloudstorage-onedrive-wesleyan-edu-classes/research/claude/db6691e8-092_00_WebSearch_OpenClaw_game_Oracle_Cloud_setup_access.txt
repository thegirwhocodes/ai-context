## Overview

OpenClaw can run as a persistent Gateway on Oracle Cloud's Always Free ARM tier. Oracle Cloud's Always Free tier provides 4 ARM CPU cores, 24GB of RAM, 200GB storage, with no expiration.

## Getting Started with Oracle Cloud

To start, head to oracle.com/cloud/free and click "Start for free." Fill in your details, verify your email, and set a password. Oracle will ask for a credit card for identity verification only. During signup, you'll pick a home region, which is permanent — you cannot change it later.

## Instance Setup

The VCN Wizard creates a public subnet, an internet gateway, proper routing, and security rules that allow SSH. After selecting the aarch64 image, Oracle may automatically switch your shape to VM.Standard.A1.Flex — that's what you want.

## Initial Configuration

To connect, use SSH to your public IP address and update system packages with `sudo apt update && sudo apt upgrade -y`. You should set hostname, set a password for the ubuntu user, and enable lingering to keep user services running after logout.

## Gateway Access

You can verify Tailscale Serve is running and check that the gateway is listening on port 18789 with `curl http://localhost:18789`.

The setup typically takes several hours to complete, and you can self-host OpenClaw with Ollama for $0/month using Oracle Cloud's Always Free tier.
