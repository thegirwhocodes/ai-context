# Sabi Path to Scale

**Core decision (March 31, 2026):** Focus on kids first, API later. Every platform started as a product. Prove it works, then extract the pipeline into an API. - c7a8b090

## Phases
- **Phase 1 (Now → Q4 2026):** Prove it works. April 15 think tank (10 kids), then 150-350 kid pilot with TaRL pre/post. Target 0.25-0.35 SD. Cost ~$2K-5K. - c7a8b090
- **Phase 2 (Q1-Q2 2027):** Get funded with pilot data. Pitch Mastercard, Gates, UNICEF, LASUBEB, World Bank HOPE-EDU. One $100K grant funds 5,000 kids. Zero-rate with MTN/Airtel. - c7a8b090
- **Phase 3 (H2 2027):** API emerges naturally. At 5,000+ kids, pipeline is battle-tested. Other orgs ask to use voice system. Wrap in API, charge $0.04-0.15/min. - c7a8b090
- **Phase 4 (2028):** Two-product platform. Sabi for Organizations (managed, per-student) + Sabi for Developers (API, per-minute). - c7a8b090

## Two Products
- **Sabi for Organizations:** Turn-key education delivery. $2-15/student depending on scale. Buyers: governments, UN, foundations, telco CSR. - c7a8b090
- **Sabi for Developers:** Hosted African voice AI API. $0.04-0.15/min. Undercuts Vapi/Retell 40-65%. Only Africa-optimized provider. Buyers: ed-tech, fintech, health NGOs, government digital services. - c7a8b090

## Key Insight
The API is the business model that makes Sabi sustainable. The kids are the business model that makes Sabi *fundable*. Right now we need funding, not customers. - c7a8b090
