## sabi-server — voice runtime (`voice_realtime.py`, the biggest behavior change)
Read the full month diff. The feedback system was rebuilt from a passive end-of-call ask into an **interactive mid-call feedback conversation**:
- New `_consume_feedback_hotkey()` drains the DTMF queue, latches `*`, and **re-queues non-`*` digits** so the numeric keypad fallback still works. Hotkey detection is wired into both `play_pcm_with_barge` (barge mid-sentence) and `wait_for_utterance`.
- `handle_mid_call_feedback()` is the new flow: record + transcribe + save the note → generate **one guardrailed empathy sentence** via the LLM (with a fixed caring fallback on failure) → deterministic "keep learning or stop?" → `_wants_to_continue_lesson()` decides resume vs. `feedback_then_stopped`. Bias is "any non-empty engaged answer = continue; bare no/stop-markers = stop."
- `record_feedback_note()` now **returns the transcript** and sets `self.feedback_captured` so the end-of-call offer doesn't double-ask. Explicit press/spoken request **overrides restricted feedback mode**.
- Also in this file: an **unclear-audio retry ladder** (`MAX_UNCLEAR_RETRIES=2`, escalating from generic repeat → "move phone closer, quieter spot, say it slowly"), a **keypad numeric fallback** (press digits + `#`, tagged `keypad_numeric_fallback`), and a **numeric-ambiguity confirmation** ("I may not have heard the full amount…").

## sabi-server — STT (`stt.py`)
- **Silero VAD pre-gate** (`_has_speech`, commit `aeeb0a3`): no speech above threshold → returns `no_speech/vad_gated` **without calling the model**, killing hallucinate-on-silence. Fail-open, toggle `SABI_STT_VAD_GATE=0`.
- **Number biasing** (`3358dae`): when a numeric answer is expected, local Whisper gets `NUMBER_HOTWORDS` and **drops the verbose prompt** (prompt made short clips echo it back); Groq (no hotwords) gets a `NUMERIC_PRIMING` sentence instead, plus a `local_numeric_salvage` retry when Groq returns a non-number.
- **Intron async path**: on `403` (non-integrator key) it falls back to `/file/v1/upload` + `/file/v1/status/{file_id}` polling, pads short WAVs to 1.2s, handles `429 Retry-After`. Sync-first, prod lane stays isolated.
