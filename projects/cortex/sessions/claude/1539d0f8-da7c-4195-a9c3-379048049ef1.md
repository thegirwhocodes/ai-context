## Category 1 — Real correctness bugs (fix before more testers)

1. **Meta webhook cross-tenant DM misroute (F1, High).** From the provider-readiness audit: `cortex_integrations` unique key is `(user_id, provider, provider_user_id)`, so two users can both register the same Instagram or WhatsApp id. The Instagram webhook returns the *first* active match — that means Naomi's DMs could route to another tenant's account. WhatsApp webhook uses `.maybeSingle()` and would 500. Fix: verify asset ownership at connect, partial unique index `(provider, provider_user_id) WHERE status='active'`, deterministic routing. Not shipped.
2. **Instagram long-lived token expiry (F2).** Instagram Login tokens are ~60 days; no `ig_refresh_token` cron. Every user reconnects every ~60 days silently. Should be a daily cron.
3. **Facebook-Page IG stores ~1h short-lived tokens (F3).** Skips `fb_exchange_token` for long-lived — one-hour tokens is the wrong long-term behavior.
4. **`total_items_synced` inflates on webhook retries (F4).** Cosmetic but confuses the Integrations dashboard's numbers.
5. **PR #55 Golden Hour Phase A is "READY, MERGEABLE"** — the tokens/primitives commit is safe to merge even without UI phase B–E. Leaving it as a stale open PR is technical debt.

## Category 2 — Gap between the "$500 chief of staff" pitch and what actually works

Pitch claims (from your recent messages): reads every account · alerts you when you haven't replied · sends all emails from one place · follows up on your goals until done · never lets you drop a ball. Reality check on each:

- **"Reads every account"** — Gmail ✓, Google Calendar ✓, Instagram DMs ✓ (only for professional/creator accounts, needs Meta App Review for non-Naomi users). WhatsApp business ✓ needs Business Cloud API. **iMessage is local-export only** (Full Disk Access script), not live. **WhatsApp personal is impossible** (no Meta API for it). Files/Notes (PR #20) unfinished — Apple Notes only via local script.
