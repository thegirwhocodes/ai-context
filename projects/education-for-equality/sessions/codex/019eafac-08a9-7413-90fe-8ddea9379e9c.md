## Codex · 2026-06-10T05:15:11.952Z · final_answer

Yes, it is possible. The important distinction: we should not embed every full app. We should build **interactive product slices** that feel live, are safe, fast, and honest.

**Research Verdict**
The strongest pattern is “site as product,” not “portfolio as gallery.” Brian Lovin calls his site an “over-engineered playground,” Josh Comeau’s best-known work is interactive guides, and Maggie Appleton’s site works because each piece has its own visual world. That supports your instinct: the mold should break in the project section.

Technically, this is feasible in Next.js:
- **Asymmetric layout:** yes. Use CSS Grid with 12 columns, cards spanning `7/5`, `8/4`, etc., with offset rows. True browser-native masonry is still limited, so we should not rely on masonry; use deliberate grid placement instead.
- **Live map for Go:** yes. Mapbox GL JS + Directions API can show a real route/ETA. We can also hardcode Wesleyan route data if we want no API cost.
- **Cortex voice agent:** yes, but with caveats. Browser text-to-speech is easy; speech recognition is not fully baseline across browsers. Best version: click-to-talk or typed fallback, with a scripted “Hello Naomi, here’s what’s on your plate” agent surface.
- **Dactyl:** yes. MediaPipe’s web hand landmarking can run in-browser, but webcam needs permission. Best version: default to a polished canned ASL/keypoint loop, with an optional “try webcam” mode.
- **Bethel:** yes. A guided Bible-study generator can be simulated or powered by a small API route. It should show “question → OT/NT references → study path.”
- **Rings:** yes as a concept demo. It should not literally send messages from the public website. Show the agent drafting/checking in/queueing warmth. The real sending-agent version is a separate product build.
- **Adjutant:** yes, but I’d keep it lower-status: “offline paperwork prototype,” with a form-fill/citation demo, no GitHub link.

**The Layout**
What you described is basically a **staggered product wall**:
- Sabi remains a full-width flagship.
- Dactyl could be a wide card, Bethel a narrower but taller card pushed down.
- Cortex gets a dark voice-agent block.
