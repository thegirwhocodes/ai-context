### `/Users/naomiivie/Education for Equality/curriculum-app/lib/rag/retrieval.ts`
Purpose: pgvector query layer for Sabi system-prompt enrichment.
- `export interface RetrievedChunk { lessonId, chunkText, chunkType, module, subject, similarity, metadata }`.
- `export async function generateEmbedding(text): Promise<number[]>` — POSTs to local `/api/rag/embed` (a sibling Next route, presumably calling self-hosted sentence-transformers on the Hetzner server). Throws on non-OK.
- `export async function searchCurriculum(query, { module?, subject?, matchCount = 3 } = {}): Promise<RetrievedChunk[]>` — embeds query, then `supabase.rpc('search_curriculum', { query_embedding, match_count, filter_module, filter_subject })`. Returns `[]` on error (logs to console). Maps row keys from snake_case to camelCase.
- `export async function getSabiCurriculumContext(currentModule: number, lastSessionSummary?: string): Promise<string>` — entry point used by `callSabi`/`callSabiVoiceFast`:
  1. Maps `currentModule` → `sabi-diagnostic|sabi-counting|sabi-addition|sabi-subtraction|sabi-multiplication|sabi-division|sabi-word-problems`.
  2. Query string = `"${moduleName} teaching ${lastSessionSummary}"` if provided, else `"${moduleName} teaching foundational numeracy"`.
  3. Two parallel searches: one filtered to the specific module (matchCount 2), one to subject `numeracy` broad (matchCount 2).
  4. Deduplicates by `lessonId + chunkType`.
  5. Returns empty string if 0 chunks (so caller falls back).
  6. Otherwise returns `\n\n## CURRICULUM CONTEXT (Retrieved for this session)\n[${TYPE}] ${text}\n\n[${TYPE}] …`.
- Env: `NEXT_PUBLIC_APP_URL` (or defaults to `http://localhost:3000`), `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`.

## Voice pipeline walkthrough (sabi-voice page → providers)

When a child taps the orb on `app/sabi-voice/page.tsx` and starts speaking:

1. **Permission + setup.** Browser prompt via `navigator.mediaDevices.getUserMedia({ audio: { echoCancellation, noiseSuppression } })`. Mic stream cached in `mediaStreamRef`. Voice support test on mount disables the orb if no `MediaRecorder` or `getUserMedia`.

2. **Greeting (first turn only).** `startCall()` calls `getSabiResponse([])` → POST `/api/sabi` with empty messages and `student_id`. The server route (not in this scope) calls `lib/voice/sabi-shared.callSabi([], studentId, isVoice=false)` for the web path. Because messages is empty, sabi-shared injects `{ role: "user", content: "Hi, I want to learn!" }` and Claude generates the warm greeting using `SABI_CORE_PROMPT + curriculumContext + memoryContext` (no voice addendum for the web orb because `isVoice=false` on this `/api/sabi` route; the addendum is normally added on phone routes, but the orb also speaks the text — that's the one stylistic quirk).

3. **TTS playback.** `speakText(greeting)` POSTs to `/api/sabi/tts` with `{ text: normalizeMoneyForSpeech(greeting) }`. The Next route calls `synthesizeSpeech(text)` in `lib/voice/tts-client.ts`:
   - **Provider 1**: `synthesizeWithElevenLabs(text)` — POST `https://api.elevenlabs.io/v1/text-to-speech/oC2pCZZWEDRe6lmZpaaw` model `eleven_flash_v2_5` with stability 0.28, similarity 0.7, speed 1, speaker boost on. Returns mp3 Buffer.
   - **Provider 2 (if ElevenLabs fails)**: `synthesizeWithChatterbox(text)` — POST `https://api.eduforequality.org/afro-tts/tts` with `{ text, format: "mp3", exaggeration: detectExaggeration(text) }`, 20s timeout. The Hetzner GPU box runs Chatterbox Turbo with Naomi's cloned Nigerian voice.
   - **Provider 3 (if both fail)**: `synthesizeWithYarnGPT(text)` — POST `https://yarngpt.ai/api/v1/tts` with default voice `Wura`.
   - If everything fails the route returns non-OK; the browser falls back further to `window.speechSynthesis` (Web Speech API) — see step 6.
4. **Browser plays audio.** The page tries `new AudioContext().decodeAudioData(arrayBuffer)` first (low-latency, gapless), falls back to `<audio>` element with `URL.createObjectURL(blob)` if decode fails. Stored in `activeTtsPlaybackRef`. `interruptSpeakOutput()` stops and frees both kinds plus cancels any in-flight TTS fetch via the `AbortController`.

5. **Auto-listen turn (`runTurn`)**. After TTS resolves, the page calls `startListening()`:
   - Creates an `AudioContext` + `AnalyserNode` (fftSize 512) for volume-based silence detection.
   - `MediaRecorder` with `audio/webm;codecs=opus` if supported. Records in 250ms chunks.
   - The silence-detect loop (`requestAnimationFrame`) reads frequency bins, computes mean volume; if > 15 it marks `didDetectSpeech`. After speech, 1500ms of silence stops the recorder. Hard cap 15000ms.
   - On stop, if `didDetectSpeech` and blob > 1000 bytes, POSTs to `/api/sabi/stt` as multipart `audio`. Server route calls `lib/voice/stt.transcribeAudio(buffer, "audio/webm")` → POST `https://api.groq.com/openai/v1/audio/transcriptions` (whisper-large-v3, English, verbose_json).
   - **Confidence gate**: if `data.confidence < 0.4` returns empty string (drops hallucinations/noise). Else returns `data.text`.

6. **LLM turn.** Page calls `getSabiResponse([…prevMessages, userMsg])` → POST `/api/sabi` → `callSabi(messages, studentId, false)`. Inside `callSabi`:
   - Parallel `getStudentMemory(studentId)` + `getStudentModule(studentId)`.
   - Try `getSabiCurriculumContext(currentModule)`: embeds query "sabi-addition teaching foundational numeracy" via `/api/rag/embed`, runs `supabase.rpc("search_curriculum", { query_embedding, match_count: 2, filter_module: "sabi-addition", filter_subject: "numeracy" })` twice (module-filter and subject-only), dedupes, formats `[CONCEPT] …`.
   - If empty/error, falls back to `getModuleCurriculum(currentModule)` (the hardcoded module text).
   - Builds final system prompt = core + curriculumContext + memoryContext (no voice addendum on this web path; on the phone path `voice/llm/route.ts` uses `SABI_SYSTEM_PROMPT` or `callSabiVoiceFast`).
   - `anthropic.messages.create({ model: "claude-haiku-4-5-20251001", max_tokens: 300, system, messages })`. Returns text.

7. **Wrap-up auto-save.** After the assistant reply lands, the page tests `looksLikeLessonWrapUpAssistantMessage(response) && transcriptEligibleForLessonCheckpoint(finalMessages)`. If true (and not already persisted), it POSTs `/api/sabi/session` with `{ student_id, messages, duration_seconds }`. Then refetches `/api/sabi/student?browser_id=…` so the orb screen shows the new `total_sessions` count next time.

8. **Loop.** `setTimeout(runTurn, 100)` chains the next listen → STT → LLM → TTS turn until the user taps End Call. End Call triggers `interruptSpeakOutput()`, stops the recorder, releases the mic, and (if ≥ 2 messages and not persisted yet) writes the final session.

**Phone-call variant** (not invoked by sabi-voice page but uses the same lib): Africa's Talking POSTs the recording URL to `/api/voice/at/*`, the route uses `lib/voice/audio-storage.downloadAudio(recordingUrl)` → `transcribeAudio` → `callSabiVoiceFast` (Cerebras → Groq → Claude Haiku) → `synthesizeSpeech` → `uploadAudio(buffer, filename)` to bucket `sabi-audio` → `createPlayAndRecordResponse(publicUrl, callbackUrl)` XML reply. Twilio variant uses `lib/voice/twiml.ts`.

## RAG flow walkthrough (student question → curriculum context → Claude prompt)

For a returning student on Module 2 (Addition) who asks "What is 200 plus 150?":

1. **Server route handler** (e.g. `/api/sabi`) receives `{ messages: [...prevTurns, { role: "user", content: "What is 200 plus 150?" }], student_id: "uuid…" }`.
2. **`callSabi(messages, studentId, isVoice)`** in `sabi-shared.ts` fires two parallel Supabase reads:
   - `getStudentMemory(studentId)` → `sabi_students` row + last 5 `sabi_sessions`. Produces the "STUDENT CONTEXT: RETURNING STUDENT" block with name, sessions, current_module 2, accuracy stats, per-skill percentages, time-since-last-session, previous summaries, plus an explicit "follow LESSON STRUCTURE" instruction.
   - `getStudentModule(studentId)` → `current_module = 2`.
3. **`getSabiCurriculumContext(2)`** in `lib/rag/retrieval.ts`:
   - Maps `2 → "sabi-addition"`.
   - Builds query `"sabi-addition teaching foundational numeracy"`.
   - `generateEmbedding(query)` → POST `/api/rag/embed` returns a `number[]` (likely a 384- or 768-dim vector from the Hetzner sentence-transformers model).
   - First `searchCurriculum(query, { module: "sabi-addition", subject: "numeracy", matchCount: 2 })` — pgvector RPC `search_curriculum` returns top-2 chunks restricted to the addition module (i.e. one of the `generateSabiModuleChunks()`-seeded entries, plus possibly more if the seed contained multiple addition variants).
   - Second `searchCurriculum(query, { subject: "numeracy", matchCount: 2 })` — same query, no module filter, lets relevant foundational-numeracy lesson chunks (e.g. `fn-2-1: Addition with Tens`) surface.
   - Dedupe by `lessonId + chunkType`. Format:
     ```
     ## CURRICULUM CONTEXT (Retrieved for this session)
     [CONCEPT] Module 2: ADDITION. Teach through buying multiple items …
     [CONCEPT] Adding Tomatoes and Peppers — …
     [PRACTICE] …
     ```
4. **Prompt assembly** in `callSabi`:
   ```
   SABI_CORE_PROMPT
   + "## CURRICULUM CONTEXT (Retrieved for this session)\n[CONCEPT] …\n[CONCEPT] …"
   + (isVoice ? VOICE_SYSTEM_ADDENDUM : "")
   + "## STUDENT CONTEXT: RETURNING STUDENT\n- Name: …\n- Current module: 2 (addition)\n…"
   ```
5. **Claude call**: `anthropic.messages.create({ model: "claude-haiku-4-5-20251001", max_tokens: isVoice ? 200 : 300, system: assembledPrompt, messages })`. Sabi answers from inside that scaffold ("Yes! Two hundred naira plus one hundred and fifty naira is three hundred and fifty naira. That's what we call ADDITION…").

**Failure modes & fallbacks**:
- If `/api/rag/embed` is down → `generateEmbedding` throws → `searchCurriculum` catches and returns `[]` → `getSabiCurriculumContext` returns `""` → `callSabi` falls back to `getModuleCurriculum(2)` (the hardcoded module text from `MODULE_CURRICULUM`).
- If pgvector rows aren't seeded yet → `search_curriculum` returns empty → same fallback.
- The result is the system prompt is never empty even pre-seed: `SABI_CORE_PROMPT + getModuleCurriculum(2)` always works.

This is what reduces per-turn token cost from ~20,500 (full prompt + all 6 modules) to ~6,500–10,500 (core + one module's worth of RAG chunks).

## Key tradeoffs / TODOs surfaced in comments

- `sabi-shared.ts`: Cerebras → Groq → Claude Haiku fallback exists because "Cerebras ~2100 tok/s → 200-token response in ~0.1s; Groq ~330 tok/s → 0.6s; Claude ~1s but always reliable." Naomi's voice loop needs < ~1s for natural turn-taking.
- `call-state.ts`: "Using DB instead of in-memory map because Vercel serverless functions are stateless."
- `audio-storage.ts`: Bucket must be public — needed for AT `<Play>` URLs; service role bypasses RLS.
- `twiml.ts`: `language: "en-GH"` (Ghanaian English) is "closest supported African English in Twilio" for STT.
- `tts-client.ts` streaming: "TTFA drops from ~300ms (full buffer) to ~80ms (first chunk)" — streaming endpoint exists (`synthesizeSpeechStream`) but the current `sabi-voice/page.tsx` only uses the non-streaming `/api/sabi/tts` blob path. Migrating to MediaSource streaming would be a future latency win.
- `is-lesson-wrap-up-message.ts`: "Tune patterns here if LLM wording drifts — keep aligned with VOICE_SYSTEM_ADDENDUM."
