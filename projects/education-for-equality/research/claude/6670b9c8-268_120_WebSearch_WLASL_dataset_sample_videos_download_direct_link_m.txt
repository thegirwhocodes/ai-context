## Official Sources for WLASL Dataset Videos

The WLASL dataset is described in "Word-level Deep Sign Language Recognition from Video: A New Large-scale Dataset and Methods Comparison". WLASL is the largest video dataset for Word-Level American Sign Language (ASL) recognition, which features 2,000 common different words in ASL.

### How to Download Videos

The official repository includes sample code demonstrating how to download data samples (video_downloader.py). The main options for accessing the dataset are:

1. **GitHub Repository**: You can clone the official repository for downloading, and it's suggested to read the README before using the dataset.

2. **Pre-processed Videos**: Pre-processed videos for the full WLASL dataset are available on request by submitting a video request and agreeing to terms of use through a Google Form. You will get links to the missing videos within 7 days.

3. **Kaggle**: WLASL datasets are also available on Kaggle (though the search results show access redirects).

### Important Licensing Information

All the WLASL data is intended for academic and computational use only, and no commercial usage is allowed. You must read and agree with the Computational Use of Data Agreement (C-UDA) terms before using the dataset.

For direct assistance, you can contact dongxu.li@anu.edu.au for help with downloading issues.
