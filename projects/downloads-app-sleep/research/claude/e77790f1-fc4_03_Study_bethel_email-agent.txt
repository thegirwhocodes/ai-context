## 3. **src/guardrails.ts** — Deterministic Safety (Code, Not Prompts)

**Core safety mechanisms:**

1. **Autonomy Tiers** (lines 9, 38–48):
   - **Tier 0:** Read-only; no drafts, labels, or sends
   - **Tier 1** (default): Drafts only (staged, not sent)
   - **Tier 2:** Auto-label/archive low-risk threads
   - **Tier 3:** Send to known contacts only; new recipients always escalated
   - Function: `canAutoExecute(action, cfg): boolean`

2. **Sensitive Topics** (lines 19–28):
   - Regex patterns that ALWAYS trigger escalation:
     - Financial: `invoice|payment|wire|bank|refund|charge|ach|venmo|zelle|paypal`
     - Credentials: `password|reset|verification code|2fa|one-?time code|account recovery`
     - Legal: `lawsuit|legal|attorney|subpoena|contract|nda|liability`
     - Medical: `medical|diagnosis|prescription|health record`

3. **The Send Gate** (lines 30–36):
   - `assertSendAllowed(): never` throws an error unconditionally
   - **There is no `sendEmail()` method anywhere in the codebase**
   - This is code-level enforcement, not prompt-based

4. **Escalation Triggers** (lines 50–59):
   - `requiresEscalation(recipient, bodyForSensitivityScan, cfg): boolean`
   - Returns `true` if:
     - Recipient is NOT in `cfg.knownContacts`
     - Body text matches `SENSITIVE_PATTERNS`

5. **Untrusted Content Framing** (lines 61–64):
   - `quarantine(emailBody: string): string` wraps text in `<untrusted_email>…</untrusted_email>` tags
   - Signals to Claude that this is data to analyze, never instructions to follow

6. **Kill Switch** (lines 66–69):
   - `killSwitchEngaged(cfg): boolean` checks if a file exists at `cfg.killSwitchPath`
   - If present, agent refuses to run
