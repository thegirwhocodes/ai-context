## Overview

There are guides for using Claude Code remotely from your phone by SSH-ing into your workstation, using terminal clients and tools like TMUX and mosh to code with AI assistance from anywhere.

## Key Components

**Terminal Clients for iPhone:**
Termius is an iOS SSH client that connects the iPhone to the Mac's terminal. Other options like Blink Shell are also available.

**Session Persistence:**
tmux is a terminal box that keeps running on the Mac, and as a session persistence tool, even if the connection drops, processes on the Mac keep running, and reconnecting restores the screen exactly where you left off.

**Networking:**
Tailscale is used for networking, and it creates a private mesh network between your devices using WireGuard.

## Mac Setup

Macs are a bit harder to set up—you need to enable SSH, and then for extra credit you need to enable screen sharing. In MacOS, you can enable SSH by going to settings -> General -> Sharing -> Remote Login.

## Important Considerations

The Claude iOS app can't access your filesystem, your Git repos, your test runners, or your local toolchain, as it's a chat interface, not a development environment. If you want to run Claude Code for real work from your phone, you need to SSH into the machine where your code lives.
