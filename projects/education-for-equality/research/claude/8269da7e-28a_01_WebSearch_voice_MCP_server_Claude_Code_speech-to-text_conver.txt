I found several voice MCP servers for Claude Code that enable speech-to-text conversation capabilities. Here's what's available:

## Main Voice MCP Servers

**VoiceMode** - VoiceMode enables natural voice conversations with Claude Code. It uses OpenAI Whisper for speech-to-text and OpenAI TTS for speech output. Installation can be done via plugin marketplace or manually.

**Voice Hooks** - Voice Mode for Claude Code allows you to have a continuous two-way conversation with Claude Code, hands-free, using the new Claude Code hooks to deliver voice input to Claude while it works. Voice recognition and text-to-speech are handled by the browser, so there is nothing to download, and no API keys are needed.

**Voice MCP** - A Model Context Protocol server that enables voice interactions with Claude and other LLMs, requiring only an OpenAI API key and microphone/speakers. It supports voice conversations with Claude, multiple transports (local microphone or LiveKit room-based communication), and OpenAI-compatible speech processing services.

**Spokenly** - It offers state-of-the-art local models, voice dictation in claude.ai, plus MCP integration for Claude Code. Spokenly runs a local MCP server that exposes voice dictation, allowing Claude Code to call this server when it needs your input instead of pausing for typed text.

**Local Voice MCP** - A local MCP server that provides voice tools for Claude Code - speech-to-text using Whisper and text-to-speech using Supertonic.

Each offers different features, with some focusing on local processing for privacy and others supporting cloud services.
