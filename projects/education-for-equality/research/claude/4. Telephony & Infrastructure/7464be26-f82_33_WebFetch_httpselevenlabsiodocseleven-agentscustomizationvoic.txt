# Expressive Mode Compatibility

**Supported Models:** Expressive mode works exclusively with Eleven v3 Conversational. The documentation does not mention Flash v2.5 or other models supporting this feature.

**Enabling Expressive Mode:**

According to the guide, there is no separate toggle. Instead, "Expressive mode is enabled by default when you select Eleven v3 Conversational as your agent's TTS model."

**Setup Steps:**

1. Navigate to your agent configuration in the ElevenLabs dashboard
2. Go to the **Agent Voice** tab
3. Select **V3 Conversational** as your Text to Speech model
4. Expressive mode activates automatically with this selection
5. Optionally, add tone guidance to your system prompt to direct emotional delivery

The documentation emphasizes that this model is "the most emotionally intelligent, context-aware Text to Speech model available in ElevenAgents" and maintains the same pricing as other ElevenLabs TTS options ($0.08 per minute).
