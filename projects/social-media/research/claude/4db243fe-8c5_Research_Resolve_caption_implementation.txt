## Key Limitations Discovered
- The Python API cannot add transitions between clips (use FCPXML workaround)
- `SetProperty` on TimelineItem sets static values only -- keyframed animation requires Fusion compositions
- No API to export DRX/PowerGrades programmatically (must use Gallery UI)
- OpenCaptions relies on an undocumented API behavior for reading subtitle text
- Text+ has no single "opacity" input -- use Merge Blend or BrightnessContrast Gain
