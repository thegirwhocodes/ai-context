# SIP Trunk Setup with Africa's Talking

Based on the help article, here's what's provided:

## Requirements
"A PBX server(on cloud or on premise)" is the only technical prerequisite listed.

## Setup Process

The documentation outlines these steps:

1. **Apply for a voice phone number**
2. **Complete KYC verification** - "We share a KYC document with you that you sign"
3. **Pay for the phone number** (pricing available at africastalking.com/pricing)
4. **IP Whitelisting** - "You share your trunk's(PBX) IP address for whitelisting"
5. **Configure callback URL** - Once IP is whitelisted, update the callback URL via dashboard (Voice → Phone Numbers → Actions → Callback URL)
6. **URL Format**: "trunk:trunk_ip_address eg: trunk:127.0.0.1"
7. **Test** - "You can now set up your PBX and test"

## Important Limitation

The article provides **no details** on:
- Specific ports or protocols

- Call routing mechanics
- Asterisk-specific configuration
- Network/firewall requirements
