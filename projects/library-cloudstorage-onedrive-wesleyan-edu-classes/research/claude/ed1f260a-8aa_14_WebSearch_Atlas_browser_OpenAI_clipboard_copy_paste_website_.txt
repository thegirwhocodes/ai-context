## Atlas Browser Overview

ChatGPT Atlas is a Chromium-based web browser developed by OpenAI that embeds the ChatGPT assistant directly into the browsing experience. Users can open a side panel in any tab and ask questions about the page, summarize content, or compare information across sites.

## Clipboard & Copy-Paste Functionality

An important security development: Agent tasks now use an isolated clipboard separate from your clipboard. This is a significant privacy and security feature.

However, researchers have identified vulnerabilities. A "Copy link" button actually places a malformed URL plus a hidden prompt into the clipboard. When the user pastes it into the Atlas omnibox, URL parsing fails and Atlas falls back to treating it as a prompt.

## Website Permissions

Permission dialogs now clearly state which site is requesting access. Atlas asks before any site can use sensitive features like the camera, microphone, or location. Permissions are set per site, so you stay in control.

## Additional Security Considerations

Users should limit tool permissions and audit which GPTs can access clipboard, files, or publishing actions.
