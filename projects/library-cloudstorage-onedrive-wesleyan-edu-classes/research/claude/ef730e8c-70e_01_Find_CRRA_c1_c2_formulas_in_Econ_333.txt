**The Diamond-Dybvig Model Setup:**

The planner solves:
```
max π u(c₁) + (1 - π)u(c₂)
{c₁,c₂}

subject to: πc₁ + (1 - π)c₂/R = 1
```

**First-Order Conditions:**
```
πu'(c₁) = πλ
(1 - π)u'(c₂) = (1 - π)λ/R

or: u'(c₁) = Ru'(c₂)
```

**Solution for c₁* and c₂*:**

The slides show that the solution is characterized as:
```
(c₁*, c₂*) with c₁* < c₂*
```

**For the specific log utility case with u(c) = ln(c):**

The first-order conditions yield:
```
π/c₁ = πλ
(1 - π)/c₂ = (1 - π)λ/R
```

Which leads to: **c₂ = Rc₁**
