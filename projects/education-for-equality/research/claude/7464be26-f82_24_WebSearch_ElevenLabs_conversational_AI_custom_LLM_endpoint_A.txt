## Custom LLM Integration

Custom LLM allows you to connect your conversations to your own LLM via an external endpoint. Using your own custom LLM is supported by specifying the endpoint we should make requests to and providing credentials through our secure secret storage.

## API Format and Request/Response

Your custom LLM will receive requests that include tools in the standard OpenAI format, meaning ElevenLabs expects endpoints that are compatible with OpenAI's API structure. 

For example, when integrating providers like Together AI or Groq, the Server URL should specify the OpenAI-compatible API endpoint (e.g., https://api.together.xyz/v1).

## Configuration Details

When setting up a custom LLM endpoint, you typically need to:
- Specify the Server URL (endpoint)
- Provide a Model ID
- Store credentials via secure secret management
- Configure parameters like temperature, token limits, and reasoning effort

## System Tools Support

System tools are automatically included in the `tools` parameter of your chat completion requests when configured in your agent. This allows your custom LLM to trigger functions for controlling conversation flow.

For more detailed API documentation and request/response examples, you can refer to the [official ElevenLabs documentation on custom LLM integration](https://elevenlabs.io/docs/agents-platform/customization/llm/custom-llm).
