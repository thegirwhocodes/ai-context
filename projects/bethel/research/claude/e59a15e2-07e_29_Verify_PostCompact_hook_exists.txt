**Yes, PostCompact is a real hook event in Claude Code.** Your previous agent was correct. However, the reason you didn't see the output in your context after compaction is likely due to how hook output is handled.

22. SessionEnd

## Hooks That Fire on Compaction

Two hooks fire during the compaction process:

- **PreCompact**: Runs BEFORE context compaction starts
- **PostCompact**: Runs AFTER context compaction completes

Both hooks support matchers for `manual` (user-triggered `/compact`) or `auto` (automatic context window compaction).

## Hook Output: stdout vs stderr Behavior (Critical)

This is where the confusion likely lies. **Hook output does NOT automatically appear in Claude's context for most events:**

| Exit Code | Behavior |
|-----------|----------|
| **Exit 0** | For `UserPromptSubmit` and `SessionStart` hooks: stdout IS added to Claude's context. For all other events (including `PostCompact`): stdout is shown only in **verbose mode** (`Ctrl+O`), NOT in the regular context. |
| **Exit 2** | Stderr is fed back to Claude as error feedback (blocking). |
| **Other codes** | Stderr appears in verbose mode only. |

## Why Your PostCompact Hook Output Disappeared

If you configured a `PostCompact` hook with exit code 0, the stdout output would NOT be injected into Claude's context automatically. It would only be visible in verbose mode.

To actually re-inject context after compaction, you have two options:

**Option 1: Use SessionStart hook with "compact" matcher** (recommended)

```json
{
  "hooks": {
    "SessionStart": [
      {
        "matcher": "compact",
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Your context reminder here...'"
          }
        ]
      }
    ]
  }
}
```

`SessionStart` hooks with exit code 0 DO inject stdout into Claude's context. The matcher `"compact"` ensures it only runs after compaction.

**Option 2: Use PostCompact with JSON output**

If you want to use `PostCompact` directly, you'd need to return JSON with a structured decision field (though the documentation examples don't show context injection for PostCompact, so SessionStart with the "compact" matcher is the official pattern).
