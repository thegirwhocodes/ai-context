## Key Points About Voice Testing

For Voice, the sandbox is not operational. This is an important limitation to understand - Africa's Talking Voice API doesn't work in sandbox mode, and every call you make during development will be a real call that costs real money and rings a real phone.

## Getting a Test Number

Instead of using a simulator, the process is automated: Log in to your Account>click on the app>Voice> Phone number>Under Voice-Phones>fill in the request form>(Product section)>Voice Service>Country> agree to terms>Category>select "Test Number" on the voice form. You will be issued with a live number to use in the production account for a 2 weeks test period after which it will be removed.

## Creating Virtual Numbers

For development purposes, to create a virtual voice number use this link: https://sandbox.africastalking.com/voice/create. Manage all the call interaction from a webhook you set up here: https://sandbox.africastalking.com/voice/phones.

## Testing Environment

The interactions with these resources occur in the SIMULATOR: https://simulator.africastalking.com:1517/ and NOT the HANDSET for all development and tests on the sandbox.

The important takeaway is that while other Africa's Talking services (SMS, USSD, etc.) have sandbox simulators, voice calls require real phone numbers and incur actual costs.
