## PHP Implementation

Actions can be chained to create an XML string using the voice->messageBuilder() method, with record() being one available action. 

The Record action in PHP supports the `finishOnKey`, `maxLength`, and `timeout` parameters which are built into the XML output string.

The available recording options in PHP include:
- `trimSilence` - Boolean to specify whether to remove initial and final silent parts of a recording, and `playBeep` - Boolean to specify whether the API should play a beep when recording starts
- `callbackUrl` - URL to forward the results of the Recording action

## PHP Example

The basic pattern shown is:
```php
$voiceActions = $voice->messageBuilder();
$xmlresponse = $voiceActions->getDigits($options)->say($text)->record()->build();
```
