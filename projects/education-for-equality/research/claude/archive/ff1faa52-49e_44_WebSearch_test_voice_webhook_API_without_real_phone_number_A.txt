## Testing with ngrok and Twilio

ngrok is a free tool that lets you put the web app running on your local machine on the Internet. This is the most common approach for testing Twilio voice webhooks locally. Start your local server (for example, on port 3000). In a separate terminal, start ngrok: ngrok http 3000.

You can run `twilio phone-numbers:update <your Twilio phone number> --sms-url "http://localhost:3000/sms-reply"` which will automatically generate an ngrok tunnel from Twilio to your locally running Function, so you can start sending texts to it. You can apply the same process but with the voice-url flag instead if you want to test with Twilio Voice.

## Alternatives to ngrok

Stripe, Twilio, and other providers have their own CLI tools with webhook forwarding. Best for: Development focused on a single provider. Additionally, if you already use Cloudflare, Cloudflare Tunnel (formerly Argo Tunnel) is free and well-maintained.
