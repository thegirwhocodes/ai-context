## GPU Server Requirements & Specifications

**For Speech-to-Text (ASR):**
Transformer models require NVIDIA GPUs for concurrency and low latency, with a single T4 or A10 able to handle 50 to 100 active streams while maintaining sub-300ms performance. Production speech-to-text typically runs on A100 or RTX 6000 Ada rather than H100, as the workload benefits more from memory bandwidth than raw compute.

**For Text-to-Speech (TTS):**
GPU memory consumption scales efficiently, from 450MB at batch size 1 to 1.8GB at batch size 32. One active request per GPU instance is the typical concurrency limit for real-time systems across architectures.

## Scaling Strategies

Scale by increasing GPU instances rather than relying on large single-GPU configurations, with queueing absorbing spikes that exceed immediate GPU capacity. A tiered approach works well: development uses cloud A5000 or RTX5000 instances, medium production uses multiple A100s in parallel for batch processing, and high-volume production uses load-balanced clusters of A100s with queuing systems.

## Production Deployment Considerations

Production constraints include latency ceilings that disrupt conversational flow, concurrency limits that restrict scale, and systems failing when they exceed latency ceilings, hit concurrency quotas, or accumulate unsustainable processing costs. MIG partitioning achieved the highest request throughput and reliability for production voice AI pipelines.
