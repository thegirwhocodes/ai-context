## Voice API & IVR

HollaTags Voice API Technology allows developers create faultless call logic for any application, software, browser, or existing system and also attune it to their special needs. The platform supports various use cases including:
- Delivering OTP and 2-Factor Authentication tokens securely via phone calling for bank payment authorisations
- Local Inbound DID Numbers for receiving calls directly to your personal numbers or routed to your application
- Interactive Voice Response (IVR) script integration to allow callers to serve themselves
