## Claude · 2026-08-01T22:43:40.138Z

A few ways, depending on what you mean:

**In Claude Code (terminal):**
- Open another terminal tab/window (`Cmd+T` / `Cmd+N` in your terminal) and run `claude` again — each is an independent session with its own context.
- `claude --resume` in a new window to pick up a past session instead of starting fresh.

**In the Claude desktop/web app:**
- `Cmd+N` opens a new chat window.
- Click the sidebar "New chat" button for a new conversation in the same window.

**Multiple Claude Code sessions on the same project:**
- Just `cd` into the project in each new terminal and run `claude` — they don't conflict, but they don't share context either.
- For voice, your global config already handles the mic lock (`wait_for_conch=true`) so parallel voice sessions politely queue.

Which flavor did you mean — terminal, desktop app, or something else?

## Claude · 2026-08-01T22:44:17.171Z

Got it — in the Claude Code desktop app:

- **`Cmd+N`** → new window (fresh task, own Files|Chat|File layout)
- **`Cmd+T`** → new tab in the current window
- Or click the **`+`** in the top bar / task switcher

Each window/tab is its own conversation with its own working directory. Your `arrange-current` layout helper runs per-task, so each new window will lay itself out the same way.

Want them side-by-side? Drag one window to half the screen, or use macOS's window tiling (hover the green button → "Tile Window to Left/Right").
