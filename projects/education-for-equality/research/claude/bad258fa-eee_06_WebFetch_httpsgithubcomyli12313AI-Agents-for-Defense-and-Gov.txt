# Port Sentinel Hackathon Project Summary

## Placement
The team "did not win the hackathon, but put in a winning effort," according to their GitHub README.

## Project Description
Port Sentinel built a comprehensive platform combining two key components:

1. **Port City Vulnerability Scanner** - identifies potentially vulnerable Industrial Control Systems (ICS) and SCADA devices in port cities using Shodan data
2. **Maritime Port Digital Twin Dashboard** - visualizes port IoT devices with vulnerability assessment and attack vector analysis

## Technical Stack
- Python 3.8+
- Streamlit (web interface)
- Pandas (data processing)
- Folium (interactive maps)
- OpenAI API (optional AI-enhanced analysis)
- Shodan API (for real-world device discovery)

## Problem Solved
The platform addresses port infrastructure security by combining geographic vulnerability scanning with digital twin visualization to "provide security insights for port infrastructure."

## Team
Kshitij Kumar Parashar, Thomas Ewing, Sara Hekmaty, and Yingquan Li

The submission was for the SCSP and AGI House Hackathon 2.0 in Arlington, VA (March 2025). No judges' comments, prize amounts, or competing team information appears in the provided content.
