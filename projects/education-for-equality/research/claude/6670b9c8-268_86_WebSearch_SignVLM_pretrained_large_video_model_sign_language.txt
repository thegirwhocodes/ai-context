## Overview

SignVLM is a pretrained large vision model for sign language recognition (SLR). The model explores the capability of the contrastive language-image pre-training (CLIP) model for SLR, using it to extract spatial features from sign video frames while a Transformer decoder is used for temporal learning.

## Model Performance

The proposed model has been evaluated on four different sign languages using the KArSL, WLASL, LSA64, and AUSTL datasets with different evaluation settings including zero-shot and few-shot learning, and outperformed other models on the KArSL, WLASL, and LSA64 datasets.

The code and data are available at https://github.com/Hamzah-Luqman/signVLM. This GitHub repository is where you can find the pretrained model weights and implementation code for SignVLM.
