## SignVLM Overview

SignVLM is the official implementation of the paper "SignVLM: A Pre-trained Large Vision Model for Sign Language Recognition." The architecture includes a trainable Transformer decoder, trainable local temporal modules, pre-trained models, and a fixed image backbone using CLIP.

## Fine-tuning with Custom Data

SignVLM is a pretrained large vision model for sign language recognition that explores the capability of the contrastive language-image pre-training (CLIP) model for SLR. The model extracts spatial features from sign video frames while a Transformer decoder is used for temporal learning.

Different evaluation settings have been followed including zero-shot and few-shot learning, with the model's performance demonstrated across different numbers of training samples starting with zero-shot until fine-tuning on the whole training data.

## WLASL Dataset Integration

SignVLM has been evaluated on the WLASL dataset using the split provided with the dataset, and it has been tested on four different sign languages including WLASL.

## GitHub Repository

The code expects training and validation data in a specific format with command line arguments for training list paths and validation list paths, where paths point to video files with integer labels, and --num_classes must be specified.
