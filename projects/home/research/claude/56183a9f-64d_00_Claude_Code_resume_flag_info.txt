Perfect! Here's what the `--resume` flag does:

## `claude --resume` Overview

**What it does:** Opens an interactive session picker to browse and resume previous Claude Code conversations in your project.

**Entry points:**
- `claude --resume` (no args) - Opens the session picker
- `claude --resume <name>` - Resumes a named session directly
- `claude --continue` - Resumes the most recent session (no picker)
- `/resume` - Switch sessions from within an active session

## Session Picker Options & Interaction

When you run `claude --resume`, you get an interactive picker with these keyboard shortcuts:

| Action | Key |
|--------|-----|
| Navigate | `↑` / `↓` |
| Expand/collapse groups | `→` / `←` |
| Resume selected | `Enter` |
| Preview content | `Space` |
| Rename session | `Ctrl+R` |
| Search/filter | `/` or any character |
| Show all worktrees | `Ctrl+W` |
| Show all projects | `Ctrl+A` |
| Filter by git branch | `Ctrl+B` |
| Exit | `Esc` |

## What's shown

Each row displays:
- Session name (if set) or summary/first prompt
- Time since last activity
- Message count
- Git branch

Forked sessions appear grouped under their root session—expand with `→` to see branches.

## Key behaviors

- **Search**: Paste a PR URL to find the session that created it
- **Multi-worktree**: Default shows sessions from current worktree; `Ctrl+W` widens to all
- **Naming**: Set names with `-n` flag at startup, `/rename`, or `Ctrl+R` in picker for easy resumption

This makes it practical to juggle multiple parallel tasks without losing conversation history.
