## Core Architecture

Real-time bidirectional systems for translating sign language use computer vision and transformer-based models to enhance accessibility for deaf and hard of hearing users.

## Processing Streaming Input

The Transformer looks at a sliding window of keypoint frames and learns the temporal relationships between them. This approach enables processing of continuous video streams without requiring complete sentences.

## Handling Variable-Length Sequences

Because the system deals with continuous streams without explicit word boundaries, the model is trained using Connectionist Temporal Classification (CTC) loss, and a CTC decoder (using either fast greedy search or more accurate beam search) collapses probabilities into a discrete sequence of glosses.

CTC enables sign language transformers to align variable-length sign videos with text without precise timing labels, allowing end-to-end recognition and translation with strong performance.

## Modern Improvements for Real-Time Performance

Recent 2025-2026 approaches address streaming latency:

- An Adaptive Transformer architecture combines convolutional feature extraction, log-sparse self-attention, and an adaptive gating mechanism to efficiently model both short- and long-range temporal dependencies in sign language sequences.

- The Adaptive Masking module dynamically removes redundant video frame representations, improving temporal alignment, while the Local Clip Self-Attention module learns hierarchical representations at both local clip and full-video levels using a refined self-attention mechanism.

## End-to-End Translation

Sign language glosses need to be translated into grammatically correct spoken language, which is achieved by routing the gloss sequence through a Large Language Model (LLM).
