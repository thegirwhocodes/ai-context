## Minimum Requirements

To prepare a private server for OpenClaw, you need a Linux VPS with full administrative access, which is the foundation of your project because an always-on server ensures your bot never sleeps.

**Hardware Specifications:**
- Linux operating system (Ubuntu 22.04 or 24.04 works great)
- At least 2GB RAM (4GB recommended for better performance)
- 10GB+ disk space for Docker images, application data, and logs
- Administrative access (root or sudo privileges) and Docker and Docker Compose
