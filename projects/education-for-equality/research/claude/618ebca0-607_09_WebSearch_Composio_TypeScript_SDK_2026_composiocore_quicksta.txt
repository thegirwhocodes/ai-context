## Overview

The TypeScript SDK provides a modern, type-safe way to interact with Composio's services and is designed for both Node.js and browser environments, offering full TypeScript support with comprehensive type definitions.

## Installation & Setup

The @composio/core package can be installed using npm, yarn, or pnpm with `npm install @composio/core`. The TypeScript SDK requires Node.js 18+ with npm, pnpm, or bun.

Basic initialization looks like:
```typescript
import { Composio } from '@composio/core';
const composio = new Composio({ apiKey: 'your-api-key' });
```

## Core Features

The core Composio SDK allows users to interact with the Composio Platform and provides a powerful and flexible way to manage and execute tools, handle authentication, and integrate with various platforms and frameworks.

The SDK includes functionality to list, retrieve, and execute tools, organize and manage collections of tools (toolkits), create and manage event triggers, configure authentication providers, and manage third-party service connections.

## Authentication & Connected Accounts

If a tool requires authentication (e.g., Gmail OAuth), Composio returns an auth URL, and the user authenticates via a Connect Link with Composio managing the tokens.

The Composio SDK provides a powerful way to manage third-party service connections through Connected Accounts, allowing you to authenticate with various services and maintain those connections.

## Framework Integration

Composio has official provider packages for both OpenAI Agents and Anthropic Claude, with TypeScript installations of @composio/openai-agents or @composio/anthropic.
