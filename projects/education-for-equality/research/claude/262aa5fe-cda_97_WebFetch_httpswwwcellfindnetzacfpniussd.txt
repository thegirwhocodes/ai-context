# NI USSD Technical Details

Based on the Cellfind webpage content provided, here's what's available about Network-Initiated USSD:

## Definition & Core Function
NI USSD (Network Initiated Unstructured Supplementary Service Data) is described as "an instant message sent from a network to a mobile device." It enables companies to initiate communication sessions where recipients can respond without incurring charges.

## Key Characteristics
- **Network-initiated**: The company/network sends the first message, unlike traditional USSD
- **Device compatibility**: Works on "all standard phones" and "all South African networks and handsets"
- **No internet required**: Functions without recipient internet connectivity
- **Cost model**: Recipients are not charged for the session

## Use Cases
Real-world applications mentioned include:
- One-time passwords (OTP) for banking authentication
- Website login verification
- Internet banking security
- Call centre authentication
- Credit/debit card protection
- Customer surveys and polls
- Balance enquiries
