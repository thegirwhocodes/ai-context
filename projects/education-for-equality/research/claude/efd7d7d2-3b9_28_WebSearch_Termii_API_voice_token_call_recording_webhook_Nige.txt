## Voice Token API

Termii offers a Voice Token API endpoint at `https://BASE_URL/api/sms/otp/send/voice` that accepts parameters including `api_key`, `phone_number`, `pin_attempts`, `pin_time_to_live`, and `pin_length`.

## Voice Call API

The voice call API enables you to send messages through the voice channel to a phone number, with only one-time-passwords (OTPs) currently allowed, and these OTPs cannot be verified using the Verify Token API.

## Webhook Support

Termii announced the release of a Webhook Dashboard, now available on the customer dashboard at accounts.termii.com. Additionally, the Inbox API allows businesses to receive inbound messages (WhatsApp & SMS) directly in applications through their set webhook URL.

## Token API Features

Termii's Token Service, in addition to SMS, Voice and WhatsApp, now supports integrating Email Token for businesses to send and verify one-time passwords (soft tokens) directly.
