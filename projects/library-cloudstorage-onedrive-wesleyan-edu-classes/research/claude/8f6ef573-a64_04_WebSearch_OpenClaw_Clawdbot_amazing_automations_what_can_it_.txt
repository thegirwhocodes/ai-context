OpenClaw is a self-hosted AI agent that connects messaging apps like WhatsApp and Telegram to a coding agent running on your desktop. It gained significant attention with 60,000+ GitHub stars in 72 hours.

### Task & Calendar Automation
Every 15 minutes, OpenClaw looks through new text messages, and if it finds you've made a specific promise about doing something tomorrow, it will create a calendar event for you the next day when you're free.
