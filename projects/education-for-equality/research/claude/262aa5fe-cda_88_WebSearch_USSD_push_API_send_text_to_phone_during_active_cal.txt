## USSD Push API Overview

USSD Push (also known as Network-Initiated or Mobile Terminating USSD) is when the application starts the USSD session on the handset, as opposed to mobile-initiated USSD where users dial the short code themselves.

## Major VAS Aggregators in Africa

Several platforms provide USSD API services across African mobile operators:

1. **Africa's Talking** - Their USSD gateway is built to handle thousands of concurrent API requests at any one time, and they provide shared USSD codes on Safaricom, Airtel and Telkom in some countries, and on Airtel, Yas, Vodacom and Halotel in others.

2. **Beem** - Supports over 150 Mobile Networks across Africa & the World.

3. **VasPro** - Offers USSDs, rewards, airtime, and mobile payment solutions in Africa.

4. **Mobulk Africa** - Powers over 40 million SMS/USSD interactions monthly, using short codes across East, West, and Southern Africa.

## How USSD Integration Works

A USSD gateway is a routing server that directs information sent from a mobile phone to a third party application, and an application can register with a gateway so that when information is passed to a short-code it is forwarded to a URL via a HTTP POST request.
