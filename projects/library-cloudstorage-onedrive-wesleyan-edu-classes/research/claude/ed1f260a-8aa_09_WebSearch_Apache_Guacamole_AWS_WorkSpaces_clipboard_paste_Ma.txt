## Browser Clipboard Permissions

The reason that you cannot directly copy/paste is that most browsers have strict control of clipboard access. Browsers vary in their level of support for the Clipboard API, and the following browsers are known to support clipboard access: Google Chrome version 66 and later, Microsoft Edge version 79 or later (via the Asynchronous Clipboard API) Mozilla Firefox 63 or later (write to clipboard only) and IE10 and IE11 (via the older, synchronous version of the API).

## Mac-Specific Issues

For Mac users connecting via VNC through Guacamole, there may be key mapping issues. When trying to use Command-C within the VNC session, the Command key may appear to be unresponsive and produce a 'c' character instead.

## Workarounds

The Clipboard text area functions as an interface between the remote clipboard and local clipboard, where text from the local clipboard can be pasted into the text area, and the text is sent to the remote clipboard.

For AWS WorkSpaces specifically (outside the Guacamole context), client logs can be found in ~/Library/"Application Support"/"Amazon Web Services"/"Amazon WorkSpaces"/logs (Mac).

If you're experiencing specific permission issues, you may need to grant clipboard access permissions when prompted by your browser, particularly when using Chrome or newer browsers that support the Clipboard API.
