## Common Issues and Workarounds

It seems to be impossible or extremely erratic to copy and paste only pieces of text from a cell in JupyterLab. There are several documented problems:

1. **Text Selection Issues**: Neither the selected text nor the text of the whole cell gets into the clipboard when some text is selected.

2. **Browser Context Menu Workaround**: You can copy portions of text by using SHIFT+RIGHT_CLICK to open the browser's contextual menu rather than the notebook's menu.

3. **Copy Output to Clipboard Command**: JupyterLab has a "Copy Output to Clipboard" feature that can be accessed by right-clicking on cell output. However, this command does not consistently copy the output, and should copy the cell output content just like in the notebook, even if the active cell does not have any output.

4. **Copy Cell Output Method**: You can select cell output from beginning to end by dragging the mouse pointer past the bottom border to cause scrolling, then release the mouse button at the end and use the browser's Ctrl-C to copy the selected text.

5. **Images/Plots**: When using the "Copy Output to Clipboard" command on matplotlib plots, the clipboard may be grayed out as an image source in PowerPoint.

These appear to be longstanding issues in JupyterLab related to browser clipboard API limitations and how the interface handles cell content selection.
