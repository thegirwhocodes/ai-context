# CorrNet Setup & Installation Guide

## Prerequisites & Requirements

**Python & Framework:**
- PyTorch >= 1.13 (required for ctcdecode compatibility)
- Python 3.x (version not explicitly specified)

**Key Dependencies:**
- ctcdecode==0.4 (Linux only; alternative: pyctcdecode for cross-platform support)
- Dependencies listed in `requirements.txt`
- Optional: sclite from Kaldi for evaluation

**Install Requirements:**
```
pip install -r requirements.txt
```

## Platform Support

**Supported Systems:**
- Linux
- Windows
- macOS (Apple Silicon/Intel) - recent updates added macOS support via `macOS_cn.md` and `macOS_en.md`

**Platform-Specific Notes:**
- "ctcdecode is only supported on the Linux platform"
- Enhanced cross-platform demo available in `Demo_multi_platforms_one_click.md`

## Running the Demo

**Basic Command:**
```
python demo.py --model_path /path_to_pretrained_weights --device your_device
```

**Demo Parameters:**
- `model_path`: Path to pretrained weights
- `device`: GPU device (default: 0)
- `language`: 'phoenix' or 'csl' (default: 'phoenix')
- `max_frames_num`: Maximum frames sampled (default: 360)

**Access:** "visit `http://0.0.0.0:7862` to play with the demo"

## Demo Input Types

The demo accepts:
- **Video files**
- **Image sequences** (extracted frames)
- **Webcam input** (implied by web interface)
