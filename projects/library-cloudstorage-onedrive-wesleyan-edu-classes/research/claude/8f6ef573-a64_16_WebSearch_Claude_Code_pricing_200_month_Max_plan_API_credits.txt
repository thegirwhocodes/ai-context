## Claude Code Pricing Plans

Claude Code offers multiple subscription tiers: the Pro plan at $20 per month (or $17 if you choose annual billing), and Max plans at $100 for 5× usage or $200 for 20×.

## Max Plan Details

The Max plan at $200 provides 20× Pro usage and adds full Opus 4.5, priority access, and memory features.

## API Credits with Claude Code

If you want to use API credits through Claude Code, usage will be billed at standard API rates (distinct from Pro/Max Plan pricing). If auto-reload is enabled in your Console account, additional credits will be automatically added when your balance runs low.

## API Pricing Models

For developers using the API directly, Sonnet 4.5 costs $3 input and $15 output for requests up to 200K tokens, and above 200K tokens, rates double ($6/$22.50).

The $200 Max plan is positioned as the premium tier for power users who need unrestricted access and want to avoid hitting usage limits during intensive development work.
