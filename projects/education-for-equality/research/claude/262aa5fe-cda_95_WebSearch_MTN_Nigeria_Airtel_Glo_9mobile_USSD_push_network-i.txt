## USSD in Nigeria - General Overview

USSD is a short command codes or quick codes that facilitate interaction between a user and a service provider, and are communication protocols that mobile operators like MTN, GLO, AIRTEL and 9mobile use to provide quick services to their customers.

## Unified USSD Code Framework

Nigerian mobile network operators are implementing a new USSD code framework that requires all providers to use a unified code format, replacing their individual codes, with the Nigerian Communications Commission setting a deadline of May 17, 2023, for this implementation.

The NCC standardized USSD codes across all networks so that Glo, MTN, Airtel, and 9mobile all use the same codes for essential functions such as airtime recharge, data purchase, balance checks, and borrowing services.
