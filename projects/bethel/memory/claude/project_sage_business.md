**Why a server at all (answer to "do we need a server for the SaaS?"):** the Sage agent loop is stateful + always-on (per user: fetch Gmail → Claude classify → stage drafts on a schedule, holding OAuth tokens) — a poor fit for serverless/Vercel functions (time limits, cold starts, no persistent loop). So the split is: **frontend + control-plane + cron triggers on Vercel; the persistent worker on the isolated E4E server.** - 50605635
