## Installation Methods

OpenClaw (formerly known as Clawdbot and Moltbot) offers three primary installation methods:

### NPM/Global Installation (Recommended)
Install with a single command (npm install -g openclaw@latest), run the onboarding wizard (openclaw onboard), and start chatting with AI from any messaging platform. This method requires Node.js version 22 or higher installed on your system, and it works seamlessly on macOS, Linux, and Windows through WSL2.

### One-Liner Installation
The installer script is the recommended way to install OpenClaw. It handles Node detection, installation, and onboarding in one step.

### Docker Installation
OpenClaw supports Docker-based installations. You can run OpenClaw in a Docker container for isolated execution with the command: docker run -d --name openclaw \ -v ~/.openclaw:/root/.openclaw \ -p 18789:18789 \ ghcr.io/openclaw/openclaw:latest
