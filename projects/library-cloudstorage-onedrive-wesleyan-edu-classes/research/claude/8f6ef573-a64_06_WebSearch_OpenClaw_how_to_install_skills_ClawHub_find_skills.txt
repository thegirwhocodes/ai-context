## Automatic Skill Installation

The basic command to automatically find and install skills is `clawhub sync --all`. By default, clawhub installs into ./skills under your current working directory (or falls back to the configured OpenClaw workspace). OpenClaw picks that up as <workspace>/skills on the next session.

## ClawHub Overview

ClawHub is the public skills registry for OpenClaw, which you can browse at https://clawhub.com and use to discover, install, update, and back up skills.

## GUI Installation Method

You can install skills in the GUI by navigating to the Skills section in the browser dashboard. For example, to integrate with Google Calendar, search for calendar, and click on Install.

## Available Skills

OpenClaw's public registry (ClawHub) hosts 5,705 community-built skills as of February 7, 2026.

## Security Considerations

It's recommended to treat third-party skills as untrusted code and read them before enabling. Additionally, OpenClaw has a VirusTotal partnership that provides security scanning for skills. Before installing a skill, visit its page on ClawHub and check the VirusTotal report to see if it's flagged as risky.
