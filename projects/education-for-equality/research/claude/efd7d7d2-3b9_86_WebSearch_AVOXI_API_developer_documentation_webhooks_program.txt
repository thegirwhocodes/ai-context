## AVOXI Programmable Voice API

AVOXI allows you to implement APIs into your own customer-facing applications to tap into their global voice inventory, and the APIs are built to support Shell, Node, Javascript, Python Java, Go and C#.

## Webhooks

Webhooks are event-driven and exchange data in one direction, with the server sending automatic updates to the computer in real-time when an event is triggered.

The webhook widget is used to make custom API calls that enable AVOXI Flow Builder to communicate with different systems by retrieving or sending data, with responses from these API calls stored in variables and referenced further in the flow to make routing decisions.

## IVR and Programmable Voice

With programmable voice API, businesses can use IVR systems and voice bots to handle routine inquiries, freeing up human agents for more complex issues. AVOXI Flow Builder orchestrates routing across locations, systems, and teams, allowing you to manage both complex call flows and IVR menus from one intuitive interface.
