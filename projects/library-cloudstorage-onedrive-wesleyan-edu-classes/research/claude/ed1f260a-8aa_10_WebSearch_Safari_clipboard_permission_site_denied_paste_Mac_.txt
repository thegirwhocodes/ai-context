Safari's clipboard access is more restrictive and doesn't offer a direct setting to manage clipboard permissions. However, clipboard access is generally allowed only during direct user interactions, such as clicking a button.

For managing clipboard permissions in Safari on Mac, you can open Safari and go to Preferences, select the Websites tab, scroll down the left-hand menu to find Clipboard Access, and select the site and set it to Allow.

Additionally, ensure you're using the latest version of Safari, as updates may enhance clipboard functionality. If you're experiencing issues, you can create a new user in System Settings → Users & Groups, log into it and test copy-paste there, and if it works fine for the new user, it's likely something in your main user account (settings, prefs, extension).
