### 1. CorrNet+ (github.com/hulianyuyy/CorrNet) -- NOT SUITABLE

- **Verdict: DISQUALIFIED.** Wrong task (continuous SLR, not isolated word recognition), wrong language (German/Chinese, not ASL), and requires video frames not keypoints.

### 3. sharonn18/tgcn-wlasl on HuggingFace -- BEST OPTION

- **Pretrained weights downloadable?** YES. Four variants with actual `pytorch_model.bin` files confirmed present:
  - `asl100`: 3.4 MB (100 classes, hidden_size=64, 20 GCN stages)
  - `asl300`: 3.5 MB (300 classes, hidden_size=256, 24 GCN stages)
  - `asl1000`: 24.3 MB (1000 classes, hidden_size=256, 24 GCN stages)
  - `asl2000`: 25.3 MB (2000 classes, hidden_size=256, 24 GCN stages)
- **Input format:** MediaPipe-compatible 55 body keypoints. Shape: `(batch_size, 55, num_samples * 2)` where `num_samples=50` (frames), so input is `(batch, 55, 100)`. Each keypoint has x,y coordinates across 50 temporal frames. NOTE: The README claims "MediaPipe pose format" but the original WLASL TGCN used OpenPose (25 body - 12 excluded + 21 left hand + 21 right hand = 55). You will need to map MediaPipe keypoints to this 55-point format.
- **Dependencies:** `torch`, `numpy`, `huggingface_hub`. That's it. No CUDA required. No heavy video processing.
- **Can it run on CPU?** YES, trivially. The model is a Graph Convolutional Network -- extremely lightweight. The asl100 model is 3.4 MB. The asl2000 is only 25 MB. Pure matrix multiplications, no CNN/video processing.
- **How many signs?** 100, 300, 1000, or 2000 ASL signs depending on variant.
- **Claimed accuracy:** ">85% top-1" per the model card (though this may be optimistic -- the original WLASL TGCN paper reported ~46% on WLASL-100 top-1 for the GCN approach).
- **Estimated setup time:** 15-30 minutes. Download model, copy the `tgcn_model.py` and `configs.py` from HuggingFace, write a MediaPipe-to-55-keypoint mapping, and you're running inference.
- **Integration code available:** The repo includes `tgcn_model.py` (full model class) and `configs.py`. Complete inference example in README.

**Key integration code:**
```python
model = GCN_muti_att(input_feature=100, hidden_feature=256, num_class=2000, p_dropout=0.3, num_stage=24)
checkpoint = torch.load("pytorch_model.bin", map_location='cpu')
model.load_state_dict(checkpoint.get('state_dict', checkpoint), strict=False)
model.eval()
x = torch.randn(1, 55, 100)  # (batch, 55 keypoints, 50 frames * 2 coords)
output = model(x)
predictions = torch.softmax(output, dim=1)
```
