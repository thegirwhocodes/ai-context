I checked the current Nigerian Copyright Act and the Nigerian Copyright Commission’s registration guidance.

The important answer is: they do not need the source code to “turn on” Sabi’s copyright. Copyright already exists automatically once the original code is created and saved. Registration is mainly for evidence.

The source-code deposit allows the Commission to:

- Record the exact work, author, owner and creation year.
- Preserve a dated copy of the work.
- Issue a certificate supporting authorship and ownership.
- Provide statutory presumptions that can help in a future infringement case.

The Copyright Act expressly treats computer programs as literary works. Registration does not itself confer copyright, but the Register is initial evidence of the work and its recorded particulars. [Nigeria Copyright Act 2022, sections 43, 87 and 108](https://www.copyright.gov.ng/wp-content/uploads/2023/04/CopyrightAct2023FinalPublication1.pdf)

### What this means for the source code

The Commission’s instructions say the application must contain “a copy of the work sought to be registered.” It is therefore not merely asking for a demonstration or a technical explanation—it wants a deposited copy that identifies the protected software work. [NCC registration instructions](https://eregistration.copyright.gov.ng/ncc/help)

My recommendation is:

- Do not submit every Education for Equality repository.
- Define the registered work narrowly, for example:
  **“Sabi Core Voice Tutoring Software, Version 1.0.”**
- Submit a complete, clean snapshot of that defined component.
- Do not rely on five or ten impressive excerpts unless the NCC confirms that source-code excerpts are accepted.
- Register materially different works separately, such as:
  - Sabi core voice-learning software
  - Sabi curriculum and lesson-script collection
  - Sabi web application/interface, if desired

The NCC says one work should generally have one application, although a genuine collection can be registered under one collection title. [NCC FAQ](https://eregistration.copyright.gov.ng/ncc/faq)

### What should be excluded

A software deposit should not contain:

- API keys, passwords or real `.env` files
- Learner names, telephone numbers or database records
- Call recordings or voice-reference recordings
- Build folders, dependencies or caches
- Git history
- Third-party software binaries
- Internal operational credentials

It should contain the actual authored source files, version information, a concise code index and an integrity manifest.

### Confidentiality

The application’s registration information becomes part of the Commission’s public record and may appear online. However, the NCC says the deposited copy of the work itself should only be released to a third party with the copyright owner’s authorization. [NCC registration FAQ](https://www.eregistration.copyright.gov.ng/)

That offers some protection, but it is still a government-held copy of proprietary source code. The Act also authorizes the Commission to reproduce and store all or part of a registered work electronically.

I found no official Nigerian rule specifying:

- A maximum number of source-code pages
- A standard “first and last 25 pages” deposit
- Whether confidential portions may be redacted
- Whether a representative excerpt is sufficient for software

The page-based fees on the website relate to obtaining certified copies of paper-based works; they are not published source-code deposit limits.

### What copyright will—and will not—protect

Copyright can protect Sabi’s original:

- Python and TypeScript code
- Tutor prompts and authored orchestration text
- Curriculum and lesson scripts
- Original selection and arrangement of content
- Original interface text and visual expression

It does not protect the general idea of:

- Teaching children through telephone calls
- An AI tutor that listens and responds
- Adaptive learning as a concept
- Procedures, systems, processes or methods of operation

The Act expressly excludes ideas, procedures, processes, systems, methods of operation and concepts. Those broader elements require trade-secret practices, contracts and possibly other IP strategies—not copyright alone.

The source code is being requested primarily as the evidentiary copy of the software being registered. Therefore, the strongest approach is a complete but narrowly defined Sabi software component—not the entire company codebase and not an overly abbreviated code sample.
