# TGCN Model for WLASL - Complete Details

## What This Model Does
A **Temporal Graph Convolutional Network (TGCN) with Multi-Head Attention** for recognizing American Sign Language (ASL) words from pose keypoints. Processes temporal sequences of 55 body keypoints extracted from sign language videos.

## Model Variants

| Model | Classes | Hidden Size | Stages | Checkpoint |
|-------|---------|-------------|--------|-----------|
| asl100 | 100 | 64 | 20 | `checkpoints/asl100/pytorch_model.bin` |
| asl300 | 300 | 256 | 24 | `checkpoints/asl300/pytorch_model.bin` |
| asl1000 | 1000 | 256 | 24 | `checkpoints/asl1000/pytorch_model.bin` |
| asl2000 | 2000 | 256 | 24 | `checkpoints/asl2000/pytorch_model.bin` |

## Input Format

- **Shape**: `(batch_size, 55, num_samples * 2)`
  - `batch_size`: Number of samples
  - `55`: MediaPipe pose keypoints
  - `num_samples * 2`: Temporal frames × (x, y) coordinates
  - **Default**: (batch_size, 55, 100) for 50 frames
- **Keypoints**: MediaPipe pose format (normalized x, y coordinates)

### Option 2: Manual Loading
```python
import torch
from tgcn_model import GCN_muti_att
from configs import Config
from huggingface_hub import hf_hub_download

# Download checkpoint and config
checkpoint_path = hf_hub_download(
    repo_id="sharonn18/tgcn-wlasl",
    filename="checkpoints/asl2000/pytorch_model.bin"
)

config_path = hf_hub_download(
    repo_id="sharonn18/tgcn-wlasl",
    filename="checkpoints/asl2000/config.ini"
)

# Load config
config = Config(config_path)

# Initialize model
model = GCN_muti_att(
    input_feature=config.num_samples * 2,  # 100
    hidden_feature=config.hidden_size,      # 256
    num_class=2000,
    p_dropout=config.drop_p,               # 0.3
    num_stage=config.num_stages            # 24
)

# Load weights
checkpoint = torch.load(checkpoint_path, map_location='cpu')
state_dict = checkpoint.get('state_dict', checkpoint)
model.load_state_dict(state_dict, strict=False)
model.eval()
```
