## Current State of Claude API Audio Support

The Claude API currently accepts text and images (JPEG, PNG, GIF, WebP) but not raw audio. Passing base64/hex of WAV in a text block only gives the model a string of data; it has no audio modality to perceive tone, timbre, or meaning from the waveform.

## Voice Features in Claude Products

Anthropic launched voice input and output for Claude on iOS and Android in May 2025, then expanded the experience to web. As of the June 2026 Help Center update, Claude AI voice mode features include a full conversational interface with the ability to speak naturally, receive a spoken reply, and switch between voice and text in the same chat.

However, voice dictation streams recorded audio to Anthropic's servers for transcription, and audio is not processed locally.

## Workarounds for Transcription

Currently, developers using the Claude API for audio handling typically rely on third-party transcription services. For example, some use Deepgram or other speech-to-text providers to transcribe audio first, then send the transcript text to Claude's API.

The search results indicate that native audio input as a first-class modality (similar to how images are handled) is not yet available in the Messages API as of the search date.
