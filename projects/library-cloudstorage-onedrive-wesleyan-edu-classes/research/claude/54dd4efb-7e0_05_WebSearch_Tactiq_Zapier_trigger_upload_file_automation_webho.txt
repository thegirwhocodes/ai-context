## Integration Overview

Tactiq integrates with Zapier, allowing you to automate workflows and connect Tactiq with other applications, such as Notion, Google Docs, Slack, and more.

## Trigger Functionality

The primary trigger in this integration is "when a meeting transcript is ready." When Tactiq generates a meeting transcript, Zapier sends the transcript data to a designated webhook.

## File Upload Automation

With an automated workflow, you can automatically add records to your tool of choice each time Tactiq generates a new transcript. For example, you can automatically upload transcripts to Google Drive or Dropbox, creating either a text file or an organized document from the meeting notes.

## Webhook Integration

Webhooks simply POST data (or JSON) to a specific URL every time we see something new. Webhooks by Zapier offers GET, POST, PUT methods, which include automatic data parsing.

## Setup Instructions

To set up the integration, go to the Tactiq Dashboard, navigate to Account & Settings, and then go to Integrations. Under Automation, select Zapier to be redirected to the Tactiq integration for Zapier page.

This integration enables you to automatically route meeting transcripts to various storage and productivity tools through automated webhooks and file upload actions.
