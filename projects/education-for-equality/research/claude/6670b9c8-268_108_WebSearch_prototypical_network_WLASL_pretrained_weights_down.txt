## Prototypical Networks for WLASL

Research has explored prototypical networks specifically for sign language recognition, utilizing a Few-Shot Learning paradigm with Prototypical Networks. A Few-Shot Prototypical Network framework has been proposed adapted for skeleton-based encoders that learn a semantic metric space where signs are classified based on proximity to dynamic class prototypes, integrating a Spatiotemporal Graph Convolutional Network (ST-GCN) with a novel Multi-Scale Temporal Aggregation (MSTA) module.

## Pretrained Weights and Inference

Several resources provide pretrained weights ready for inference on WLASL:

1. **Official WLASL Repository**: To test pre-trained models, you can download WLASL pre-trained weights and unzip them into a folder I3D/archived/

2. **TGCN Model on Hugging Face**: A Temporal Graph Convolutional Network (TGCN) model is available for word-level American Sign Language recognition, trained on the WLASL dataset, which implements a Temporal Graph Convolutional Network with Multi-Head Attention that processes temporal sequences of 55 body keypoints extracted from sign language videos. The repository contains 4 pre-trained model variants with Graph Convolutional Layers, Temporal Modeling, Multi-Head Attention, and Residual Connections.

3. **Other Skeleton-Based Models**: Pretrained weights for skeleton-aware models on the WLASL2000 dataset are available to validate performance, which can be specified in the configuration file for testing.

The main WLASL GitHub repository and Hugging Face model hub are the primary sources for accessing ready-to-use pretrained weights for sign language inference tasks.
