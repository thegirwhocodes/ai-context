## Downloading Notebooks from TDM Studio

You can download the notebook locally from the GitHub repo, and it can be tricky to copy and paste text/code into Workspace, so uploading the entire .ipynb file into the environment through Workspace's upload functionality is recommended.

## Working with .ipynb Files Locally

If you want to work with downloaded TDM Studio notebooks on your local machine, here are the general approaches:

1. **Running Jupyter Locally**: You can clone the repo containing the ipynb notebook, go to the path where the ipynb is cloned, and open Jupyter notebook to see the file using the command `jupyter notebook $filename`.

2. **Uploading to TDM Studio Workbench**: You can upload scripts or any type of file to the Jupyter environment by following the Upload instructions.ipynb file in the Jupyter notebook.

## TDM Studio Workbench Environment

When using the actual TDM Studio workbench, TDMStudio workbench is a virtual Windows machine deployed and controlled by ProQuest that loads your selected datasets automatically into that environment.
