## Google Calendar MCP Overview

Google Calendar offers a remote Model Context Protocol (MCP) server that allows AI agents to securely interact with Google Calendar data. By configuring the Google Calendar MCP server, you enable AI applications like Gemini CLI, Claude, or IDEs to perform actions in Google Calendar.

## Core Capabilities

The Google Calendar MCP server provides a standardized way for AI agents to read data like listing calendars and retrieving events, and take action like creating, updating, and deleting events.

## Remote MCP Setup

Google has released fully-managed, remote MCP servers where Google's existing API infrastructure is now enhanced to support MCP, providing a unified layer across all Google and Google Cloud services, allowing developers to point their AI agents to a globally-consistent and enterprise-ready endpoint.

## Configuration Requirements

To use the Google Calendar MCP server, you must enable it in your Google Cloud project and then configure your MCP client to connect to it. The Google Calendar MCP server uses OAuth 2.0 for authentication and authorization, and you must configure the OAuth consent screen before you can create an OAuth client ID.

## Available Tools

The Calendar MCP server provides 8 tools including create_event, delete_event, get_event, list_calendars, list_events, respond_to_event, suggest_time, and update_event.
