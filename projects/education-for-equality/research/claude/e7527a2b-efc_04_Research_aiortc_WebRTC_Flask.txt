### 3. MediaTrack Pattern: Converting OpenCV Frames to WebRTC

The standard pattern for streaming OpenCV camera frames via WebRTC with aiortc uses **VideoStreamTrack** or **VideoTransformTrack**:

**Basic VideoStreamTrack Pattern (for capturing raw camera):**
```python
from aiortc import VideoStreamTrack
from av import VideoFrame
import cv2

class CameraVideoTrack(VideoStreamTrack):
    def __init__(self, camera_index=0):
        super().__init__()
        self.cap = cv2.VideoCapture(camera_index)
        
    async def recv(self):
        ret, frame = self.cap.read()
        if not ret:
            return None
        # Convert BGR (OpenCV) to RGB for WebRTC
        frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        # Create VideoFrame from numpy array
        video_frame = VideoFrame.from_ndarray(frame_rgb, format="rgb24")
        return video_frame
```

**VideoTransformTrack Pattern (for processing frames):**
```python
from aiortc import MediaStreamTrack, VideoStreamTrack
from av import VideoFrame
import cv2

class VideoTransformTrack(MediaStreamTrack):
    def __init__(self, track):
        super().__init__()
        self.track = track
        self.kind = "video"
        
    async def recv(self):
        frame = await self.track.recv()
        # Convert to OpenCV format
        img = frame.to_ndarray(format="bgr24")
        
        # Process with OpenCV (e.g., edge detection)
        edges = cv2.Canny(img, 100, 200)
        # Convert back to BGR and create VideoFrame
        edges_bgr = cv2.cvtColor(edges, cv2.COLOR_GRAY2BGR)
        new_frame = VideoFrame.from_ndarray(edges_bgr, format="bgr24")
        # Preserve timing information
        new_frame.pts = frame.pts
        new_frame.time_base = frame.time_base
        return new_frame
```

**Key conversion methods:**
- `frame.to_ndarray(format="bgr24")` — Convert WebRTC frame to OpenCV-compatible numpy array
- `VideoFrame.from_ndarray(array, format="bgr24")` — Convert numpy array back to WebRTC frame
- **Must preserve `pts` and `time_base`** for proper frame timing

### 4. Signaling Flow

WebRTC signaling establishes the peer connection via SDP (Session Description Protocol) and ICE candidates. Flask-SocketIO can handle this, though aiohttp is recommended.

**Complete signaling flow:**

```
Client (Browser)                Server (Python)
    |                              |
    |------ createOffer -------->  |
    |                          setRemoteDescription
    |                          createAnswer
    |<----- answer + ICE ------    |
    |                              |
    |<-- ICE candidates --------   |
    |---- ICE candidates -------->  |
    |                              |
    |===== SRTP encrypted =======  |
    |<---- Video/Audio stream ---  |
```

**Flask-SocketIO signaling example:**

```python
from flask import Flask, render_template
from flask_socketio import SocketIO, emit, send
from aiortc import RTCPeerConnection

app = Flask(__name__)
socketio = SocketIO(app)

pcs = {}  # Track active peer connections

@socketio.on('offer')
def on_offer(data):
    """Browser sends WebRTC offer"""
    offer_sdp = data['sdp']
    
    pc = RTCPeerConnection()
    pcs[request.sid] = pc
    
    # Set remote offer
    await pc.setRemoteDescription(RTCSessionDescription(sdp=offer_sdp, type="offer"))
    
    # Create answer
    answer = await pc.createAnswer()
    await pc.setLocalDescription(answer)
    
    # Send answer back
    emit('answer', {
        'sdp': pc.localDescription.sdp,
        'type': 'answer'
    })

@socketio.on('ice-candidate')
def on_ice_candidate(data):
    """Browser sends ICE candidates"""
    pc = pcs.get(request.sid)
    if pc:
        candidate = RTCIceCandidate(**data['candidate'])
        await pc.addIceCandidate(candidate)

@socketio.on('connect')
def on_connect():
    """New peer connection initiated"""
    pass
```

### 5. Frontend JavaScript Requirements

The client-side JavaScript must:
1. Create an RTCPeerConnection
2. Exchange SDP (offer/answer)
3. Collect and exchange ICE candidates
4. Handle the video stream

**Minimal WebRTC client example:**

```javascript
const config = {
    iceServers: [
        { urls: ['stun:stun.l.google.com:19302'] }
    ]
};

const pc = new RTCPeerConnection(config);
const socket = io();

// Listen for video tracks from server
pc.addEventListener('track', (event) => {
    const video = document.querySelector('video');
    video.srcObject = event.streams[0];
});

// Send ICE candidates to server
pc.addEventListener('icecandidate', (event) => {
    if (event.candidate) {
        socket.emit('ice-candidate', {
            candidate: event.candidate.toJSON()
        });
    }
});

// Handle ICE connection state
pc.addEventListener('connectionstatechange', () => {
    console.log('Connection state:', pc.connectionState);
});

// Initiate offer
async function startConnection() {
    const offer = await pc.createOffer();
    await pc.setLocalDescription(offer);
    
    socket.emit('offer', {
        sdp: pc.localDescription.sdp,
        type: 'offer'
    });
}

// Receive answer
socket.on('answer', async (data) => {
    const answer = new RTCSessionDescription({
        sdp: data.sdp,
        type: 'answer'
    });
    await pc.setRemoteDescription(answer);
});

// Receive ICE candidates
socket.on('ice-candidate', async (data) => {
    const candidate = new RTCIceCandidate(data.candidate);
    await pc.addIceCandidate(candidate);
});

startConnection();
```

### 6. Flask-SocketIO + aiortc Compatibility Notes

**Challenges:**
- aiortc is async-first (asyncio), Flask is synchronous
- Flask-SocketIO's `async_mode='threading'` works but isn't truly async
- Better approach: Use aiohttp + python-socketio instead

**Workaround for Flask:**
- Use `asyncio.new_event_loop()` in threads
- Or run aiortc RTCPeerConnection logic in separate asyncio loop in background threads
- Many production examples use aiohttp instead of Flask

**Flask with aiortc requires:**
```python
import asyncio
from aiortc import RTCPeerConnection

# Create loop in separate thread
loop = asyncio.new_event_loop()
thread = threading.Thread(target=asyncio.set_event_loop, args=(loop,), daemon=True)
thread.start()

# Use loop.call_soon_threadsafe() to schedule async work
```
