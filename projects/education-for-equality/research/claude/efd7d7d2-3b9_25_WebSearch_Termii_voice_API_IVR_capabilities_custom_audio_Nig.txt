## Termii Voice API Overview

Termii's Voice API enables businesses to make and receive calls through their platform, allowing them to provide personalized customer support, conduct surveys, or verify customer identities.

## IVR and Audio Capabilities

The platform supports features such as call recording, call routing, and interactive voice response (IVR) systems. This allows businesses to create sophisticated voice communication workflows that enhance the customer experience and streamline operations.

## Current Functionality

According to the official Termii developer documentation, the voice call API enables you to send messages from your application through the voice channel to a phone number. Only one-time-passwords (OTPs) are allowed for now and these OTPs can not be verified using the Verify Token API.

## Context

Termii's omni-channel platform, equipped with API capabilities, supports messaging across SMS, voice, email, and USSD channels. Termii is a Nigerian-founded communication platform as a service (CPaaS) company founded in 2017 by Gbolade Emmanuel and Ayomide Awe.
