## Voice Input Features

While Antigravity doesn't yet have a native "Intercom Mode" (bidirectional voice chat inside the editor), you can achieve this workflow by combining High-Fidelity Dictation, Gemini Live, and Strict Prompt Engineering.

### Current Voice Capabilities

You can click on the microphone icon to start dictating, and the text will appear in the editor for you to review and edit. Additionally, voice-to-text input from mobile is available (HTTPS required for mic permissions).

### Microphone Access

Upon downloading and installing the application, users get a request for microphone permissions. However, the speech-to-text feature should detect and list available system microphones, allowing users to select and use them for voice input, though the microphone discovery process has been reported to fail on some systems.

### Technical Tools for Voice Input

For high-accuracy voice input, standard OS dictation often fails with technical jargon, so tools powered by OpenAI's Whisper or similar models are recommended, with Mac users able to use Superwhisper or MacWhisper for dictating complex technical instructions directly into the Antigravity chat box with high accuracy.

### Future Plans

Expected future features include the ability to control Agents by voice, such as "Hey Antigravity, fix all the bugs in the authentication module."
