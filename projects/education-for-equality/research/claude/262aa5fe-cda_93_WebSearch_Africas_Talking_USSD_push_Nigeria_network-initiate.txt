### USSD Session Types

The search results reveal information about different USSD session types:

Network Initiated Unstructured Supplementary Service Data (NI USSD) is an instant message sent from a network to a mobile device, also known as MT USSD or Push USSD.

NI USSD allows a company to initiate the session and send the first message to which the user can respond. This is distinct from traditional user-initiated USSD where the customer dials a code.
