## JSON Mode and Structured Output in Python

The Gemini API supports two levels of structured output control: JSON Mode (setting response_mime_type to enforce JSON-formatted responses without schema constraints) and Schema-Constrained Output (combining response_mime_type with response_schema to enforce specific data structures using TypedDict definitions).

For Python specifically, the SDK automatically parses schema-constrained responses with the response.parsed attribute providing a dictionary matching the TypedDict schema structure, ready for immediate use without manual JSON parsing.

JSON Schema support has been added to all actively supported Gemini models, enabling libraries like Pydantic (Python) to work out-of-the-box with the Gemini API.

## Free Tier Rate Limits

The free tier allows 1,500 requests per day with 1 million tokens per request, and you can build and test production applications without hitting rate limits.

For more detailed rate limit information, rate limits depend on a variety of factors such as your usage tier and can be viewed in Google AI Studio, and as your tier and account status change over time, your rate limits will automatically update.

## Simple Example

Here's a basic Python example using the Gemini API with structured output:

```python
import google.generativeai as genai
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

client = genai.Client()
response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Extract: Jason is 25 years old",
    config=genai.types.GenerateContentConfig(
        response_mime_type="application/json",
        response_schema=User
    )
)
```
