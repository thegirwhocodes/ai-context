## Screen Time API Frameworks

ManagedSettings sets up the actual block, while DeviceActivity controls when that block is turned on and off. The main frameworks are FamilyControls, ManagedSettings, and DeviceActivity.

## Key Components

**FamilyControls:** FamilyControls is your gateway to understanding what the user wants to manage, providing authorization—the mechanism to request permission from the user to manage their app and web activity. FamilyControls provides UI components (FamilyActivityPicker) that allow users to easily select specific applications, categories of applications (like "Social Media" or "Games"), and websites.

**ManagedSettings:** ManagedSettings is the enforcer framework that lets you define the actual rules once you know what the user wants to restrict. ManagedSettings lets you shield apps & websites by preventing selected apps from being launched or shielding specific web domains in Safari.

**DeviceActivity:** DeviceActivity determines when the rules defined in ManagedSettings should be active, allowing you to schedule restrictions by defining specific time intervals during which the restrictions are enforced.

## Authorization Requirements

Before writing code using these APIs, you need special permission from Apple—an entitlement. You must apply for the com.apple.developer.family-controls entitlement through Apple's developer portal.
