## Recording Features

Africa's Talking allows you to record call sessions into an MP3 file that you can retrieve and play later, which is useful for "conducting surveys or ensuring quality of service in call centres."

## API Endpoints

The Voice API endpoints are:
- Live: https://voice.africastalking.com/call
- Sandbox: https://voice.sandbox.africastalking.com/call

## SDK Methods

The PHP SDK provides a `record()` method that can be used when building voice XML responses. You can chain the `record()` action with other methods like `getDigits()` and `say()` to create voice action sequences.
