## Key Sign Language Recognition Projects:

**1. American Sign Language Recognition (Transfer Learning)**
A project using transfer learning trained on a Kaggle dataset of 87,000 ASL alphabet images divided into 29 classes (26 English alphabets and 3 additional signs). It uses Google's Inception v3 as the base model with custom fully connected layers for ASL prediction.

**2. Sign Language Recognition with CNNs and RNNs**
This prototype includes code to prepare data, extract features, train neural networks, and predict signs during live demo using convolutional neural networks and recurrent neural networks (LSTM). The neural network model can be downloaded separately (150 MB).

**3. Real-time LSTM-Based Detection**
A project utilizing Long Short-Term Memory (LSTM) neural network architecture where users perform sign language gestures in front of a camera and the system instantly detects and interprets the gestures.

**4. ASL Fingerspelling Translation**
A project using transfer learning to extract features followed by custom classification, implemented in a real-time system with OpenCV reading frames from a webcam.
