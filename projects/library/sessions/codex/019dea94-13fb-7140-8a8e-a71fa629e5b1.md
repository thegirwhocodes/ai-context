## Codex · 2026-05-02T21:24:53.916Z · final_answer

Short version: probably yes for the conversation history, but not as a true “multi-account profile” setup.

Claude Code’s docs say:
- Sessions are saved locally under `~/.claude/projects/`, and resuming restores the full conversation history. [How sessions work](https://code.claude.com/docs/en/how-claude-code-works)
- You can switch accounts with `/login`. [Quickstart](https://code.claude.com/docs/en/quickstart)
- Authentication mainly affects billing/access; Anthropic says “everything else about Claude Code behaves the same way regardless.” [Usage + limits](https://support.claude.com/en/articles/14552983-models-usage-and-limits-in-claude-code)

So the practical takeaway is:
- If you switch accounts with `/login`, your current session context should generally remain because the session is local, not cloud-hosted.
- What may change is model availability, quota/billing, and permissions tied to the account.
- If you close/reopen, use `claude --continue` or `claude --resume` to keep the same conversation.

Important caveat: I don’t see official Anthropic docs saying “you can keep two different accounts active simultaneously in one live session.” In fact, there’s a public feature request suggesting true multi-account simultaneous use is not supported yet. [GitHub issue](https://github.com/anthropics/claude-code/issues/261)

Safest mental model:
- One local session file
- One currently authenticated account at a time
- Switching accounts does not necessarily wipe context, but it is not the same as having two accounts live side-by-side
