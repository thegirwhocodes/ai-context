## Recent Advances in Real-Time Sign Language Recognition (2026)

### Edge Deployment and Low-Latency Architectures

TinyMSLR is an explainable, lightweight framework designed for isolated-sign classification on resource-constrained devices, combining a ConvNeXt-Tiny encoder for fine-grained local visual cues with a Swin Transformer encoder for long-range spatio-temporal context and an adaptive fusion gate to balance both streams.

S3D-Conv1D is a spatiotemporal architecture for isolated word-level sign language recognition tailored for TinyML deployment that factorizes spatial and temporal processing into lightweight two-dimensional convolutions followed by one-dimensional convolution layers, eliminating recurrent dependencies and ensuring deterministic, MCU-compatible computation.

### Performance Metrics for Continuous Recognition

For continuous sign language recognition, recent systems demonstrate significant performance improvements. A dual-stream framework achieves an average latency of 32 ms per frame and an inference throughput of approximately 31 frames per second when running on a single RTX A6000 GPU. This framework is significantly lighter than transformer-based CSLR models, requiring only about 76 GFLOPs and 28.7 million parameters compared to models that frequently require more than 120 GFLOPs.

### Real-Time ASL Recognition Systems

A real-time American Sign Language interpretation system integrates deep learning with keypoint tracking by combining the YOLOv11 model for gesture recognition with MediaPipe for precise hand tracking to achieve high accuracy in identifying ASL alphabet letters in real time. The computational complexity is 6.5 GFLOPs per inference.

### IoT and Mobile Deployment

A hybrid framework for real-time sign language recognition tailored to IoT-enabled environments integrates a Long Short-Term Memory network for static gesture recognition and a 3D Convolutional Neural Network for dynamic gesture recognition, implemented on a Raspberry Pi device using MediaPipe for landmark extraction to support low-latency, on-device inference.
