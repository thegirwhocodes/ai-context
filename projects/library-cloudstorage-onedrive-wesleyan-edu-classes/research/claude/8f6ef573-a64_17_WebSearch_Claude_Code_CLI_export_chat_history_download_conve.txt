## Storage Location

Claude Code saves all chats in ~/.claude/projects/ as JSONL files. Additionally, ~/.claude/history.jsonl is the index, but full conversations live in ~/.claude/projects/ organized by your project paths.

## Export Options

There's no built-in export feature in Claude Code itself, but there are several third-party solutions available:

**Command-Line Tools:**
- The claude-conversation-extractor tool finds Claude Code logs automatically in ~/.claude/projects and extracts Claude conversations to clean Markdown files

- The claude-code-exporter can be installed globally with npm and supports multiple export modes for prompts, outputs, or full conversations in Markdown or JSON format

**VS Code Extension:**
- The Claude Code Assist extension (agsoft.claude-history-viewer) can be installed from the VS Code marketplace and provides a sidebar that shows all conversations with diffs, search, and one-click resumption

**Built-in CLI Commands:**
Within Claude Code sessions, you can use the /history command to see recent conversation history with dates, projects, topics, and session IDs

For the official Claude web app (not Claude Code), users can export user information and chat history from Settings > Privacy on the web app or Claude Desktop
