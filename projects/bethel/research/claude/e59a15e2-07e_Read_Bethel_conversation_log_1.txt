### 2. Architecture/Tech Stack

**4-Layer AI Architecture:**
1. **Personal Context (RAG)** -- user's dream journal, past interpretations, personal symbol dictionary
2. **Bethel LoRA** -- fine-tuned adapter (~16-20MB) on Phi-3.5 Mini (3.8B params), trained on Bible + Hagin + Kuhlman + Jackson + Virkler + dream frameworks
3. **Biblical Knowledge Base (RAG)** -- full NKJV (31,102 verses) in Supabase pgvector with 384-dim embeddings (all-MiniLM-L6-v2), dream symbol dictionary, cross-references
4. **Cloud Model Fallback** -- Claude Haiku API (~$0.0045/call) for complex reasoning

**App Platform**: React Native / Expo (the existing project uses Expo)

**Backend/Database**: Supabase with pgvector. Tables for `bible_verses`, `dream_symbols`, `user_dreams`, `user_notes`, all with vector embeddings.

**Serving**: LoRAX on Hetzner RTX 4000 SFF Ada (20GB VRAM), sharing with existing Sabi infrastructure. Additional cost for Bethel: ~$25/month.

**Future on-device inference**: CoreML/MLX on iOS (iPhone 15 Pro+), llama.cpp on Android. Phi-3.5 Mini INT4 (~2GB) + 16MB LoRA adapter.

**Training data validation pipeline**: Every theological claim scored as Aligned, Extrapolated, Testimony, or Contradicts against NKJV scripture. Contradicting items excluded entirely. Testimonies labeled as such (not doctrinal claims).
