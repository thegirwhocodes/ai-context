## Voice Mode for Claude Code

Voice Mode MCP brings natural voice conversations to Claude Code and other AI coding assistants. There are several implementations available:

1. **VoiceMode MCP**: Built on the Model Context Protocol (MCP), it provides a clean, reliable interface for adding voice capabilities to your AI workflows.

2. **mcp-voice-hooks**: Voice Mode for Claude Code allows you to have a continuous two-way conversation with Claude Code, hands-free, using the new Claude Code hooks to deliver voice input to Claude while it works.

3. **voice-mcp**: A Model Context Protocol (MCP) server that enables voice interactions with Claude and other LLMs, requiring only an OpenAI API key and microphone/speakers.

## MCP Servers and VS Code Extension

An important limitation to note: The Claude Code VS Code extension cannot connect to MCP servers, as MCP functionality works in CLI but is not supported in the VS Code extension. However, when the VS Code extension is active, it runs a local MCP server that the CLI connects to automatically, allowing the CLI to open diffs in VS Code's native diff viewer, read selections for @-mentions, and execute cells in Jupyter notebooks.

## Claude Code Voice Extension

There's a VS Code extension called Claude Code Voice that provides a voice-enabled Claude Code chat interface with native mic recording and text-to-speech.
