## Key Decisions

- Base model: Qwen3-4B for LoRA (best quality per research)
- Training infra: RunPod cloud GPU initially, dedicated server at 200+ users
- Monthly LoRA re-fine-tune (or threshold-based: 500 new data points)
- RAG for real-time data + LoRA for personality/style + Claude for reasoning
- Email prioritization: trust the AI + profile rather than building a separate system. Gmail labels for basic filtering, LoRA will learn patterns over time.
- Web-first (Next.js) over native — works on every device, fastest to build
- Don't buy GPU server until 200+ users — cloud GPU is cheaper before that
