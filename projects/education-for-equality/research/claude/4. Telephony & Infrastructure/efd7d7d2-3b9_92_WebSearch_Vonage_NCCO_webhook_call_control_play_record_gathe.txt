## What is NCCO?

NCCO (Nexmo Call Control Object) is the format for describing the various actions that will take place during a call. NCCOs define actions like audio playback, call recording, or IVR, executed during a call.

## Key Actions Supported

The NCCO framework supports several important actions:

- **Play**: Audio playback is supported
- **Record**: Record actions will record your call, with code snippets available for examples of how to authenticate and download the finished recording after the call. Additionally, when the recording completes, Vonage sends a webhook containing the recording URL so that you can download the file.
- **Gather/Input**: Dual Tone Multi Frequency (DTMF), is a form of signaling used by phone systems to transmit the digits 0-9 and the * and # characters.

## IVR Applications

This scripting of call logic allows for flexible and sophisticated voice applications, from simple notifications to complex interactive systems.

## Webhook Integration

A Nexmo Call Control Object (NCCO) is a JSON array that you use to control the flow of a Voice API call. The system operates through webhook endpoints that return NCCO instructions to control call behavior.
