## Africa's Talking SIP Trunk Setup

Using SIP trunks, Africa's Talking can connect to your Private Branch System (PBX) and allow you to make and receive voice calls.

### Key Requirements for Setup

To establish a SIP trunk connection with Africa's Talking, you'll need:

1. A PBX server (on cloud or on premise)
2. Apply for a voice phone number, sign a KYC document that Africa's Talking shares with you, and pay for the phone number
3. Share your trunk's (PBX) IP address for whitelisting, and once your IP address is whitelisted, you can change your number's callback URL from the dashboard

### Callback URL Configuration

The basic format for the callback URL is trunk:trunk_ip_address (e.g., trunk:127.0.0.1)
