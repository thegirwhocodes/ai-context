# Voice MCP Overview

## Local Processing

Yes, this project runs entirely locally without API keys. It uses:
- **Whisper** for speech-to-text via "faster-whisper (no API calls)"
- **Supertonic** for text-to-speech via "local synthesis using Supertonic (no API calls)"

## Core Features

The system provides voice tools including:
- "listen_and_confirm" - Record speech, transcribe with Whisper, return transcript
- "speak" - Synthesize and play audio through speakers
- Combined tools like "speak_and_listen" to reduce latency

## macOS Installation

The same steps apply across platforms:
1. Clone the repository
2. Install dependencies via `uv sync`
3. Configure in your Claude Code MCP settings file
4. Restart Claude Code

The project notes it was "Developed on Windows, should work on macOS/Linux."

## Hardware Requirements

Essential components:
- Python 3.10+
- A microphone for voice input
- Speakers/headphones for audio output
- Approximately 720MB storage (Whisper ~460MB, Supertonic ~260MB download on first use)

The system includes "automatic silence detection to stop recording" and supports adjustable silence parameters for different use cases.
