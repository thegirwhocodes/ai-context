## B. Recommended Stack for Naomi — defended/revised

**Verdict: keep Next.js 16 + Tailwind v4 + TypeScript + Vercel. It is the canonical 2026 founder-dev stack and matches leerob (Cursor VP DevEx), Brian Lovin (Tellescope/ex-GitHub), Guillermo Rauch (Vercel CEO), and Sahil Lavingia (Antiwork CEO).**

Concrete revisions:

1. **Keep Inter + Instrument Serif** — the pairing is "pre-harmonized" (Rodrigo Fuenzalida designed Instrument Serif with shared vertical metrics to common sans defaults). It is the 2025–2026 "editorial founder" pairing — same combo used in Linear marketing, Anthropic blog, Vercel ship pages. Do **not** swap to Calibre/Söhne/Suisse Int'l — those are proprietary ($$$) and Inter is now indistinguishable in practice. STIX Two Text (which leerob just switched to) is the only credible alternative — a true editorial serif optimized for body text — but Instrument Serif is the better display-only pairing for a portfolio with short copy.
2. **Add MDX** for `/writing` posts. Use `@next/mdx 16.1.5` (same version leerob ships). Co-locate posts as `app/writing/[slug]/page.mdx`. This avoids Contentlayer (which is unmaintained as of 2026) and avoids Notion API friction.
3. **Add `next-themes`** for system-preference dark mode. Every credible founder site in 2026 supports `prefers-color-scheme` (leerob, brianlovin, joshwcomeau, sahillavingia all do). Do not default to dark — default to **system**.
4. **Add `@vercel/analytics`** + **Vercel Speed Insights**. Both are free on the Hobby tier and ship via one import each. Skip Plausible/Fathom unless you specifically want public analytics ($14+/mo).
5. **Add `@vercel/og`** for per-page OG images. Free, edge-cached, 500KB bundle, 800ms p50 generation.
6. **Add JSON-LD `Person` schema** — leerob ships one in his root layout; it's the single biggest SEO/AEO win for a founder name search.
7. **Add `app/sitemap.ts` + `app/robots.ts`** (Next.js conventions, no library needed).
8. **Add an RSS feed** at `app/rss/route.ts` returning `application/rss+xml`. Use the `feed` package (~3KB).
9. **Skip Framer Motion for now.** React 19.2 ships native `<ViewTransition>` integration with Next 16's `viewTransition: true` config. Use that instead — saves 60KB+.
10. **Skip Contentlayer, skip MDXRemote, skip Sanity, skip Notion-as-CMS.** All add complexity without payoff at your stage.

## E. Performance / SEO Checklist (15 items toward Lighthouse 100)

1. **`next/font/google`** for both Inter and Instrument Serif with `display: 'swap'` and `preload: true`. Subset to `latin` only (saves ~30KB).
2. **Self-host critical assets**, never load fonts from a third-party CDN at runtime. `next/font` does this automatically.
3. **`metadataBase`** set in root layout: `new URL('https://naomiivie.com')`. Without this, OG image absolute URLs break.
4. **Static `opengraph-image.tsx`** at `app/opengraph-image.tsx` (Next picks this up by filename) + per-route dynamic OG via `app/api/og/route.tsx` using `@vercel/og`.
5. **`twitter-image.tsx`** sibling (Next auto-generates Twitter card meta).
6. **`app/sitemap.ts`** with `MetadataRoute.Sitemap` return type. Lists all routes + MDX-derived writing slugs.
7. **`app/robots.ts`** returning `MetadataRoute.Robots`.
8. **JSON-LD `Person` schema** in root layout (see code section G below). Targets Google Knowledge Panel.
9. **Canonical URLs** via `metadata.alternates.canonical` per page.
10. **`<html lang="en">`** + `suppressHydrationWarning` (required by `next-themes`).
11. **No client-side analytics in `<head>`** — use `<Analytics />` from `@vercel/analytics/react` at the body bottom. Defers entirely.
12. **Disable `themeTransitionOnChange`** in `next-themes` config (`disableTransitionOnChange`) — kills the FOUC during system theme switches.
13. **Add Speed Insights**: `import { SpeedInsights } from "@vercel/speed-insights/next"`. Free on Hobby.
14. **Favicon set via `app/icon.tsx`** (auto-generated SVG with first initial — leerob style) or static `app/icon.png` (32×32) + `app/apple-icon.png` (180×180). Next produces all sizes.
15. **Use `<Link prefetch>` (default) and `priority` on the hero image** if any. LCP targets: <1.2s on 4G; Core Web Vitals all green; CLS = 0 (which font-display:swap can break — use `next/font` to fix).

Lighthouse-100 target for a personal site of this size: **100/100/100/100** is realistic. leerob and patrickcollison both hit this.

## F. Animation / Interaction Recommendations

**Do these three (and only these):**

1. **Native View Transitions API.** Enable `experimental.viewTransition: true` in `next.config.ts`. Wrap navigations with React 19.2's `<ViewTransition>` component for free 200ms cross-fades. Falls back to no-op in Safari/Firefox.
2. **Underline-on-hover for inline links.** leerob does exactly this: `underline decoration-neutral-500 decoration-1 underline-offset-[2.5px] hover:decoration-neutral-400`. It's the 2026 "engineer-tasteful" pattern — visible but not loud.
3. **Subtle fade-up on first-load for hero only** (~200ms, ease-out, `prefers-reduced-motion` aware). Use pure CSS keyframes, not Framer Motion.

**Never do these three:**

1. **Custom cursors.** They are dated, accessibility hostile, and signal "designer trying too hard" in 2026.
2. **Parallax scroll on the hero.** Done to death 2019–2023; now reads as cheap.
3. **Page-load splash screens / loader animations / typewriter effects on the name.** Founder sites are read 3–8 seconds — every animation steals reading time.

Optional fourth: **`scroll-driven animations` (CSS)** for project cards fading in on scroll. Native CSS in 2026 — no JS needed: `animation-timeline: view()`.

```ts
const SITE = 'https://naomiivie.com';

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const writingDir = path.join(process.cwd(), 'app', 'writing');
  let posts: string[] = [];
  try {
    const entries = await fs.readdir(writingDir, { withFileTypes: true });
    posts = entries.filter(e => e.isDirectory()).map(e => e.name);
  } catch {}

  const staticRoutes = ['', '/about', '/work', '/writing'].map(p => ({
    url: `${SITE}${p}`,
    lastModified: new Date().toISOString(),
    changeFrequency: 'monthly' as const,
    priority: p === '' ? 1.0 : 0.7,
  }));

  const postRoutes = posts.map(slug => ({
    url: `${SITE}/writing/${slug}`,
    lastModified: new Date().toISOString(),
    changeFrequency: 'yearly' as const,
    priority: 0.6,
  }));

  return [...staticRoutes, ...postRoutes];
}
```

```tsx
import { useTheme } from 'next-themes';
import { useEffect, useState } from 'react';

export function ThemeToggle() {
  const { resolvedTheme, setTheme } = useTheme();
  const [mounted, setMounted] = useState(false);
  useEffect(() => setMounted(true), []);
  if (!mounted) return <span className="size-5 inline-block" />;
```

## H. Answers to the specific implementation questions

1. **Font pairing**: keep Inter (400, 500, 600) + Instrument Serif (400 normal + 400 italic). Confirmed as the 2026 "editorial founder" pairing.
2. **Dark mode**: yes, **system-preference default** via `next-themes`. Do not default to dark.
3. **View transitions**: yes — native, free, 220ms cross-fade only. Don't reach for Framer Motion.
4. **Custom OG**: yes, one static `app/opengraph-image.tsx` for home + one dynamic `app/api/og/route.tsx` for `/writing/[slug]`.
5. **JSON-LD Person schema**: yes, in root layout. Single biggest AEO/SEO win.
6. **RSS feed**: yes, if you publish writing. Adds ~3KB. Skip if no `/writing` section.
7. **Analytics**: `@vercel/analytics` + `@vercel/speed-insights`. Both free, both one-line imports.
8. **Vercel Hobby limits to watch**: 100GB bandwidth/mo (plenty), 100GB-hours functions/mo, **no commercial use** (you're a student/personal — fine). OG images count as function invocations — Vercel caches aggressively (CDN-cache + tag-based; you'll never hit limits with a personal site).
9. **Custom domain**: buy `naomiivie.com` via Cloudflare Registrar (cheapest, no markup). In Vercel project → Domains → add both `naomiivie.com` and `www.naomiivie.com`. Set `naomiivie.com` as primary, configure `www` → 308 redirect to apex. DNS at Cloudflare: A `@` → `76.76.21.21`, CNAME `www` → `cname.vercel-dns.com`. Cloudflare proxy **off** (orange cloud → grey) — Vercel handles the edge.
