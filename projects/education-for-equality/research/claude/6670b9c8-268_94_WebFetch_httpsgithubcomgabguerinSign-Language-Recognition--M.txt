# Sign Language Recognition - MediaPipe & DTW Implementation

## How It Works

This system recognizes sign language gestures by extracting hand landmarks and comparing temporal patterns. Here's the workflow:

**Landmark Extraction**: MediaPipe's Holistic Model extracts keypoints from hands, pose, and face. Currently, the implementation focuses on hand landmarks only.

**Feature Representation**: Rather than using raw coordinates, the system creates "invariant to orientation and scale" features by computing angles between hand joint connections, making it robust to different positions and sizes.

**Temporal Matching**: Dynamic Time Warping (DTW) compares the recorded sign's angle sequences against reference signs in the dataset, measuring similarity despite variations in execution speed.

## What DTW Matching Does

DTW is described as "widely used for computing time series similarity." It aligns two sequences of varying lengths to find the optimal correspondence, enabling recognition of signs performed at different speeds. The system computes DTW distances between the input gesture and all reference signs, then applies voting logic—only outputting predictions above a confidence threshold.

## Reference Sign Recording

**Process**: 
- Videos organized hierarchically: `data/videos/[SignName]/[video_files].mp4`
- System extracts HandModel features (joint angles) from each frame
- Stores temporal sequences of feature vectors for both hands
- Creates SignModel objects representing complete sign gestures

A helper script (`yt_download.py`) downloads French sign videos from YouTube links specified in `yt_links.csv`, with ffmpeg handling video processing.

## Accuracy & Performance

The README notes the current dataset is "insufficient to obtain good results," explicitly encouraging users to expand it. No specific accuracy metrics are provided—results depend heavily on dataset size and quality.

## Dependencies

Required packages installable via: `pip install -r requirements.txt`

Key libraries: MediaPipe (landmark extraction), OpenCV (video/webcam processing), DTW implementation library

## How to Run

```
1. pip install -r requirements.txt
2. Populate data/videos/ with reference sign videos (or run python yt_download.py)
3. python main.py
4. Press 'r' key during webcam feed to record and recognize signs
```
