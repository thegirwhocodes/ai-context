Be patient with work. Do not rush to respond. Do not skip recovery steps to answer faster.

**Why:** Multiple Claudes in this project have taken shortcuts — skipping compaction re-reads, reading only the tail of transcripts instead of the full file, claiming "I already read that" when they hadn't. Every shortcut led to wrong answers, duplicated work, or missed context. The user has had to correct this repeatedly.

**How to apply:** When instructions say "read the full file," read the full file. When instructions say "check memory first," check memory first. If recovery takes 5 minutes, take 5 minutes. The user would rather wait for a correct answer than get an instant wrong one. Do not let the pressure of "the user is waiting" override the instructions.
