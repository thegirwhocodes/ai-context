## Overview
Qwen3-TTS series (0.6B/1.7B) was released on 2026.1.22, representing completely open-source technology supporting on-premises deployment and customization.

## Installation Methods

### Pip Installation
Create a Python 3.12 environment with conda, then install the qwen-tts package via pip. For optimal GPU performance, it is highly recommended to install Flash Attention via pip install -U flash-attn --no-build-isolation.

### Model Download Options
Users can download models through ModelScope (recommended for Mainland China) or Hugging Face using pip install -U modelscope/huggingface_hub commands.

## Docker Setup

Docker setups are available for running Qwen3-TTS locally on multi-GPU rigs. Several pre-built Docker repositories exist:

- Community Docker implementations include docker compose up -d to build and launch containers, with first builds taking 15-30 minutes due to FlashAttention compilation
- Docker containers are accessible at http://localhost:8000

## GPU Requirements

A CUDA-compatible GPU with 8GB+ VRAM is recommended. 8GB GPUs like the 3060Ti may require using 0.6B models instead of 1.7B to avoid VRAM issues.

## Setup Requirements
Docker images use CUDA 12.4, and your host driver needs to be recent enough (535+). GPU-accelerated setups require PyTorch with CUDA support installed via pip install torch --index-url https://download.pytorch.org/whl/cu121.
