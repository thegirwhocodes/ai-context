## Cross-File Summary

**Blocking Flow:**
1. Timer checks every 10s if current time is in blocking period
2. On match → `startCountdown()` → 3-second countdown animation
3. After 3s → `startBlocking()` → fullscreen ambient view
4. User can `usePass()` (3 per week) to exit, or wait until wake time
5. At wake time → automatic `endBlocking()`

**Pass System:**
- **3 per week**, reset every Sunday at midnight
- Tracked in UserDefaults as array of usage dates
- `checkAndResetIfNewWeek()` compares stored reset date to current week's Sunday

**Lock Feature:**
- Prevents settings changes for 1–30 days
- Persisted to `~/.sleepwell/.lock` (survives uninstall)
- Lock expiry checked every 10s

**No Cloud/Multi-Device/AI Features:**
- All data local (UserDefaults + file system)
- No CloudKit, iCloud Sync, email, or agent/AI integration
- Single-device only

**Enforcement:**
- Unsandboxed app (no sandbox restrictions)
- Window level `.screenSaver` blocks desktop/Mission Control
- Cmd+Q blocked via `applicationShouldTerminate()`
- Launch-at-login forced enabled (can't disable)
- Sleep/wake detection re-checks blocking state
