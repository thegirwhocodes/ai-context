## What actually stands out from the code

**The learning brain is genuinely deterministic** — not just LLM vibes. `learning_state.py` has 3-level skill-specific scaffold ladders for 11 skills (counting, addition, subtraction, ×, ÷, word problems, phonemic awareness, rhyming, blending, listening comp, oral grammar). `curriculum_path.py` pins the LLM to Module→Week→Lesson with all 96 numeracy titles + 48 literacy script lessons. `numeric_grading.py` handles two-step unit-price change, total-spend, and confusable teen/tens pairs (12/20, 40/45, etc.). **Intron async fallback is wired but literacy transcription failed** — [stt.py:259](sabi-server/stt.py:259) catches `403 integrator account` on the sync endpoint and falls back to `/upload` + `/status/{file_id}` polling. Guards run on every LLM turn, `guard_output` blocks even Claude if it tries to claim humanity or solicit PII.

**voice_realtime.py has serious edge-case handling** I hadn't appreciated:
- 650ms barge-in grace period so PSTN noise doesn't cut Sabi's first frame
- Literacy mode uses lower RMS threshold (420 vs 650) + longer end-silence (18 vs 8 frames) so short letter answers register
- Keypad numeric fallback: after 2 unclear-audio retries, prompts "press digits + #" and consumes DTMF
- Numeric ambiguity confirmation bypasses the LLM entirely — a deterministic "say the naira amount again slowly" when grading is ambiguous
- Feedback recording *always* writes a sidecar with `ended_reason` (wait_timeout / dtmf_skipped / channel_closed) even when no audio captured — you can debug why every window closed

**Course rotation is between calls only** — [learning_state.py:346-420](sabi-server/learning_state.py:346) `route_next_course_after_session` requires `has_learning_evidence` (correct or wrong answer, not just "hello"), so a non-learning call doesn't consume the next subject slot.

**Shared-phone identity is built but flag-gated OFF** — `SABI_ONE_PROFILE_PER_PHONE` defaults `True` in memory.py:1354. The learner_key = normalized_phone::normalized_child_name machinery is in the code, dormant. Flip that env when child pilot starts.

**Layer C evidence is production-ready** — [pilot_evidence.py](sabi-server/pilot_evidence.py) computes TaRL level movement, per-skill mastery counts, dosage (calls × minutes × hours), pre/post effect size d, and 11 RCT-readiness cards (protocol, instruments, consent, baseline, randomization, midline, endline, data quality, learning outcomes, safety/fidelity, publication pack). CSV export supports board / evaluator / public redaction modes.
