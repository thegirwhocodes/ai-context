## Main Project Overview

A maker named Nekhil created a pair of glasses using Raspberry Pi that can help the wearer understand sign language. The camera module captures the movements of the signer's hands, while the Raspberry Pi processes the data using machine learning and translates the gestures into spoken words, with a speaker delivering these out loud.

## Hardware Components

The project originally considered using a Raspberry Pi 5, but due to size constraints, the maker chose the smaller Raspberry Pi Zero 2 W. This choice of board is priced at $15. The Raspberry Pi Zero 2 W is connected to a Camera Module V3, positioned in the front center of the glasses frame.

## Technology Stack

The platform holding together the design is VIAM, an open-source tool oriented toward smart machine projects. The project uses VIAM's machine learning model vision service with TensorFlow Lite models, specifically using a YOLOv8 model.

## Open Source Availability

Nekhil has shared all the code behind this project on GitHub, and the creator has listed all the hardware, code, and instructions on Hackster.

## Current Limitations

Although American Sign Language (ASL) is a vast language with many signs for words and phrases, this system is designed to recognize only letters for spelling.
