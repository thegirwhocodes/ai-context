# NigerianAccentedEnglish Model Overview

**Base Model & Size:**
The model is built on "Whisper Small (244M parameters)" and represents a fine-tuned version specifically optimized for Nigerian English speech patterns.

**Framework & Format:**
It uses the Transformers library with PyTorch. The implementation relies on `WhisperProcessor` and `WhisperForConditionalGeneration` classes for inference.

**Loading & Inference Code:**
```python

asr = pipeline("automatic-speech-recognition",
               model="NCAIR1/NigerianAccentedEnglish")
```
