# Intron Voice API Documentation Analysis

## Products/Endpoints Offered

The platform provides four main service categories:

1. **STT Widget**: "Quick and easy integration using our pre-built widget. Perfect for rapid deployment in web applications."

2. **Speech-to-Text File Uploads**: "Direct API access for custom implementations with audio files uploads."

3. **Speech-to-Text Streaming**: "Direct API access for custom implementations using streaming."

4. **Text-to-Speech**: "Convert text to natural-sounding speech with our TTS API."

Specific STT endpoints documented include: Streaming, Upload File Sync, Upload File, and Get File Status. TTS endpoints include: Upload Text, Get Text Status, TTS Generate, and TTS Streaming.

## Authentication

Users must obtain API credentials by:
1. Signing into voice.intron.io
2. Navigating to the developers tab
3. Copying their API key with the instruction: "Keep this secure and never expose it in client-side code."
