## Running Claude Code CLI on iPad

There are several approaches to use Claude Code on iPad:

### 1. **Termly - Direct iPad Integration**
Install the Termly CLI on your Mac or PC, run `termly start --ai claude-code` in your project folder, then open the Termly app on your iPad and scan the QR code. Your entire Claude Code session — prompts, responses, file edits, terminal output — streams live to your iPad with zero latency. Send prompts, review AI-generated code changes, approve or reject edits — all from your iPad screen.

### 2. **SSH + Terminal App + Tailscale**
Any terminal that can hold an SSH connection will get you started. Tailscale gives you private access to your Mac from anywhere. It feels like a personal VPN, without the router drama. tmux keeps terminal sessions alive across disconnects. You can detach, disconnect, come back later, and everything is still running.

### 3. **Mobile Companion Apps**
Monitor Claude Code from your iPhone or iPad. View terminal output, browse files, and approve prompts on the go. There are also third-party apps like Happy Coder that provide secure mobile access to Claude Code sessions.

### Key Considerations
Any iPad terminal experience without a real Ctrl key is going to make you miserable — every shell command needs Ctrl-C, Ctrl-D, Ctrl-R, and the soft keyboard's modifier handling is nowhere near good enough. A physical keyboard with proper modifier keys is strongly recommended.
