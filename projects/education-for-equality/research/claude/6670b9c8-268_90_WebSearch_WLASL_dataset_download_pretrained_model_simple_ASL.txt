## Official WLASL Repository

The WLASL repository contains the WLASL dataset described in "Word-level Deep Sign Language Recognition from Video: A New Large-scale Dataset and Methods Comparison". WLASL is the largest video dataset for Word-Level American Sign Language (ASL) recognition, which features 2,000 common different words in ASL.

## Getting the Dataset and Models

The repository can be cloned for downloading, and four subsets WLASL100, WLASL300, WLASL1000 and WLASL2000 are constructed by taking the top-K (k=100, 300, 1000 and 2000) glosses from the WLASL_vx.x.json file.

For pretrained models:
- To train models, first download I3D weights pre-trained on Kinetics and unzip it into a folder I3D/weights/
- To test pre-trained models, first download WLASL pre-trained weights and unzip it to see a folder I3D/archived/

## Python Inference

Sample code for loading the dataset and downloading data samples is provided in data_reader.py and video_downloader.py. The test.ipynb notebook file will load in the pretrained weights, set up the model and perform inference on the test dataset.
