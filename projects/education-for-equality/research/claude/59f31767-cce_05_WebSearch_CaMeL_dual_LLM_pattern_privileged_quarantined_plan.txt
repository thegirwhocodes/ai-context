## Overview

Google DeepMind introduced CaMeL (CApabilities for MachinE Learning) as a defense mechanism against prompt injection attacks. It leverages the Dual LLM pattern described by Simon Willison and extends it in a clever way.

## Architecture

CaMeL utilizes a dual-model architecture consisting of a Privileged LLM and a Quarantined LLM. The Privileged LLM manages task orchestration and isolates sensitive operations, while the Quarantined LLM handles potentially harmful data without tool-calling capabilities.

A Privileged LLM sees only the trusted user request and writes the plan as code without ever peeking at untrusted data. A Quarantined LLM parses untrusted content into structured fields, and it cannot call tools.

## Prompt Injection Defense

At no point is content handled by the quarantined LLM exposed to the privileged LLM. Instead, the Q-LLM populates references—like $email-summary-1—and the P-LLM can then reference them without being exposed to potentially malicious tokens.

## Key Enhancement: Capabilities

While the Dual LLM pattern provides a security enhancement, CaMeL addresses its flaws by introducing capabilities within a custom interpreter to effectively manage dependencies and security policies. The inclusion of "capabilities" allows for granular control over data manipulation and ensures that sensitive operations are performed only under trusted conditions.

CaMeL uses a custom Python interpreter to track the origin of data and instructions, enforcing capability-based security guarantees which do not require modifying the LLM itself.

## Effectiveness

CaMeL can neutralize 67% of attacks in the AgentDojo security benchmark.
