# Google Calendar MCP Server Configuration for Cursor

## (1) MCP Endpoint URL
```
https://calendarmcp.googleapis.com/mcp/v1
```

## (2) JSON Configuration

The documentation doesn't provide a Cursor-specific example. Based on the "Others" section guidance, here's the structure:

```json
{
  "mcpServers": {
    "calendar": {
      "httpUrl": "https://calendarmcp.googleapis.com/mcp/v1",
      "oauth": {
        "enabled": true,
        "clientId": "YOUR_OAUTH_CLIENT_ID",
        "clientSecret": "[REDACTED:clientsecret]",
        "scopes": [
          "https://www.googleapis.com/auth/calendar.calendarlist.readonly",
          "https://www.googleapis.com/auth/calendar.events.freebusy",
          "https://www.googleapis.com/auth/calendar.events.readonly"
        ]
      }
    }
  }
}
```

Note: The doc only shows explicit `settings.json` structure for Gemini CLI. For other clients, you'll need to consult Cursor's MCP documentation.

## (3) Required Google Cloud APIs/Services

- **Google Calendar API** (`calendar-json.googleapis.com`)
- **Google Calendar MCP API** (`calendarmcp.googleapis.com`)

Enable via:
```bash
gcloud services enable calendar-json.googleapis.com calendarmcp.googleapis.com --project=PROJECT_ID
```

## (4) Required OAuth Scopes

Per the documentation: `"https://www.googleapis.com/auth/calendar.calendarlist.readonly"`, `"https://www.googleapis.com/auth/calendar.events.freebusy"`, `"https://www.googleapis.com/auth/calendar.events.readonly"`

## (5) OAuth Client Setup

1. Create OAuth 2.0 credentials in Google Cloud Console as **Web application**
2. Add redirect URI: `https://claude.ai/api/mcp/auth_callback` (adapt for your client)
3. Configure OAuth consent screen with these scopes
4. Use generated Client ID/Secret in your config

The documentation notes: "The Google Calendar MCP server uses OAuth 2.0 for authentication and authorization."
