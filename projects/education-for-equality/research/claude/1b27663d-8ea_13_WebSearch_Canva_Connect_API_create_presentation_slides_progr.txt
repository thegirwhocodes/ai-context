### Canva Connect APIs Overview

The Connect APIs enable third-party developers to programmatically access and embed key Canva capabilities off-platform. Anyone can use the Connect APIs free of charge to build integrations that will bring Canva functionality into another platform, system, or tool.

### Creating Presentations Programmatically

With an integration you can upload your assets to Canva, programmatically create designs for your users to edit, and then export the finished designs back to your system. A presentation lets you create and collaborate for presenting to an audience.

### Advanced Features

Developers can build apps that programmatically read and update the layout and contents of a Canva design, including the size, position, and structure of individual elements, which allows apps to help users align content, adjust layouts, provide design feedback, or apply suggested edits with a single click. Additionally, with Data Connectors, apps can now bring data into Canva from external data sources like CRMs and spreadsheets, supporting dynamic content like charts, personalization at scale, and new ways to guide users through the creative process.

### Getting Started

You can follow the Quickstart to get started with a Canva-created app that demonstrates some of the main API features, and Canva has created a Starter Kit repository that includes an example web app which demonstrates some of the Connect APIs' main features.
