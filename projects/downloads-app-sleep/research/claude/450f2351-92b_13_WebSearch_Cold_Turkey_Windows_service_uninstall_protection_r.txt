## Filter Driver Protection Mechanisms

Windows Defender has a kernel-mode driver (WdFilter.sys) that registers a Registry callback filter which protects Defender's registry keys. If it is possible to unload, crash or stop the WdFilter kernel minidriver from running, the Defender service can be stopped from using the WdFilter kernel minidriver from processing events and protecting Tamper Protection and other Defender's Registry Keys.

## Windows File Protection (WFP) and Filters

Interacting with the WFP is easier because there are direct APIs available. For creating a WFP filter, the desired API is FwpmFilterAdd0, which is leveraged to create a WFP filter for both IPv4 and IPv6 addresses. Firewall rules and WFP filters are both eventually set in the registry, making it possible to monitor the registry to pick up on this activity.

## Registry and Uninstall Protection

Even if you disable a software component, the filter driver is still loaded when you restart the computer. To disable filter drivers, set the Start registry key of the corresponding filter drivers to 0x4, which will disable the filter driver.
