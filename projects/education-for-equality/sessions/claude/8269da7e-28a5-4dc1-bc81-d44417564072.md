## Voice MCPs for Claude Code — what's actually out there

**Critical caveat first:** MCP servers only work in the **Claude Code CLI**, not the VS Code extension's chat panel. The extension is sandboxed and can't spawn MCP subprocesses. The workaround is to run `claude` in VS Code's integrated terminal — same editor, just a different surface.

### The four real options

| Option | API keys? | Install effort | Notes |
|---|---|---|---|
| **VoiceMode** (mbailey) | Optional (works fully local with Whisper.cpp + Kokoro, or use OpenAI) | Easy — plugin marketplace | Most mature. MIT license. |
| **mcp-voice-hooks** (johnmatthewtennant) | None — uses browser speech APIs | Medium — settings.json config | Free, requires Claude Code 2.1.69+, Chrome/Safari. Continuous two-way conversation. |
| **voice-mcp** (jochiang) | None — fully local Whisper + Supertonic | Medium — clone repo + uv sync | ~720MB download. Privacy-max option. |
| **Claude Code Voice** (VS Code extension, not MCP) | Needs Claude API/subscription | Easy — marketplace install | Only ~1k installs, no ratings. Not battle-tested. Does work inside the extension though. |

claude plugin install voicemode@voicemode

You'd run this in the terminal (or VS Code's integrated terminal). It's not the "talk inside the chat panel" experience you might've imagined — it's "open a terminal, type `claude`, then have a voice conversation."

### What I confirmed about Antigravity

1. **It's a VS Code fork** — uses Open VSX registry, supports most VS Code extensions

4. **Known MCP limitation:** Antigravity doesn't support MCP OAuth, recommends keeping enabled tools under 50, and uses `serverUrl` instead of `url` for HTTP servers

### Why the voice MCPs I researched earlier won't work cleanly here

| Voice MCP | Why it breaks in Antigravity |
|---|---|
| **mcp-voice-hooks** | Uses **Claude Code hooks** specifically — that's a Claude Code feature, doesn't exist in Antigravity. Dead on arrival. |
| **VoiceMode (mbailey)** | Pure MCP server, *could* be added to Antigravity's config — but it was designed around Claude Code's behavior of proactively calling `converse` in a loop. Antigravity's default agent is **Gemini 3**, which has no instruction to behave that way. You'd get tools registered but no continuous conversation. |
| **voice-mcp (jochiang)** | Same problem — the tools (`listen_and_confirm`, `speak`) would be installed but the agent has to *choose* to call them. Without the right system prompt, it won't. |

The honest, working pattern from the Medium "AI CTO" voice-activated dev guide:

1. **Voice in:** SuperWhisper or MacWhisper (Whisper-based dictation, system-wide). You speak → text appears in Antigravity's chat box. Better than macOS dictation for technical terms.
