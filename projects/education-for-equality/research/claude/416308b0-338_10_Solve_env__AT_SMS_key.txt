**`AT_USERNAME` + `AT_API_KEY`** — consumed in `lib/voice/sms.ts`:
- `getSMSProvider()` (lines 22-25): returns `"at"` **only if BOTH `AT_API_KEY` and `AT_USERNAME` are set**; otherwise falls back to `"twilio"`.
- `sendATSMS()` (lines 30-50): sends `AT_API_KEY` as the `apiKey` header and `AT_USERNAME` in the form body to `https://api.africastalking.com/version1/messaging`. Also reads `AT_SENDER_ID` (optional `from`).

So with `AT_USERNAME=sandbox` + a sandbox key in production, the provider check passes (both are set) and the code will POST to AT's **live** endpoint with sandbox credentials → AT rejects it (the `response.ok` check throws `AT SMS failed: ...`). **Bottom line on what breaks:** Inbound voice calls (the actual tutoring) use none of these three. They only govern the two post-call SMS messages (session summary + practice question) and the callback-number string inside them.

## 2. Generating the production AT API key

Per AT's official help article (steps are for an account already in a **live/production** app dashboard, not sandbox):

1. Log into `account.africastalking.com`. You're in **Sandbox** by default. To leave sandbox, select your **live app** — on the dashboard there's an app switcher; pick the production app (the one tied to team/app "EduForEquality") instead of "Go To Sandbox App." (Sandbox lives at `account.africastalking.com/apps/sandbox/...`; the live app sits at `account.africastalking.com/apps/<your-username>/...`.)
2. In the live app: **Settings** (left-hand menu).
3. Click **API Key**.
4. **Enter your account password** and click **Generate**. ← this is the gatekeeping step.
5. **Copy the key immediately** and store it somewhere safe — *"you will not see it from the dashboard on subsequent visits"* (it's shown exactly once; regenerating invalidates the old one).
6. **Wait ~3 minutes before testing** the new key — AT documents a short propagation delay.

The verification/email gotcha that blocked this earlier: AT requires the **account to be fully verified** (email confirmation, and for live SMS in Nigeria, completion of their KYC / sender-ID + app activation) before the live API Key / Generate flow is usable. If "Generate" is greyed out or the live app isn't selectable, the account verification email hasn't been actioned — find AT's confirmation email (check spam) and complete verification, or contact `info@africastalking.com` / your AT account rep, before retrying step 4. There is no separate "email-verify the key" click; the verification is at the account/app level and unblocks the password-and-Generate button.

Username gotcha (important): the production `AT_USERNAME` is the **account username you chose when creating the application — NOT the app name**. AT's docs are explicit: *"This is not to be confused with the APP name."* So `EduForEquality` may be the app *name* while the actual auth username is something different. Read it off the dashboard: it's the path segment in the live app URL `account.africastalking.com/apps/<username>/settings/key`, and shown on the dashboard next to the app. Confirm that the username segment really is `EduForEquality` before committing it; if the URL shows a different slug, use that as `AT_USERNAME`.
