## Hugging Face Models

There is an open-source American Sign Language (ASL) Recognition Model available on Hugging Face (Niharmahesh/Sign_language_recognition_v1). The model processes images and provides top 5 predictions along with visualizations of detected hand landmarks.

## GitHub Projects

Several GitHub repositories offer open-source sign language recognition implementations:

- ASL language recognition using pre-trained MediaPipe models (aqua1907/Gesture-Recognition)
- A Sign Language Recognition System using MediaPipe and an MLP model that captures hand gestures, extracts landmark features, and predicts sign language letters dynamically
- An application that uses a deep learning model trained on the ASL Dataset to predict signs from input images or video frames
- Projects using pretrained I3D models that extract spatiotemporal features from video sequences

## Key Technologies

MediaPipe is an open-source framework developed by Google that provides pre-built, customizable building blocks, and many projects use the pre-built hand-tracking model of MediaPipe. Additionally, common approaches use pretrained models with TensorFlow, MobileNet, and other frameworks.
