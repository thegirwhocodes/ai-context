## Key Features

Expressive Mode gives teams unprecedented control over tone - so agents can de-escalate, reassure, and guide conversations to a clear resolution, even under pressure.

The feature is built on two main components:

1. **Eleven v3 Conversational**: Eleven v3 Conversational is ElevenLabs' most emotionally intelligent, context-aware Text to Speech model, built on Eleven v3 and optimized for real-time dialogue.

2. **Improved Turn-Taking System**: A new turn-taking system provides better-timed responses with fewer interruptions. The new turn-taking system uses real-time signals from the industry-leading transcription model Scribe v2 Realtime, to infer emotion from how something is said and better determine when an agent should speak, pause, or wait.
