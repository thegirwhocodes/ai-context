## What "patching an app" means

Traditional desktop apps (Word, Photoshop, most native macOS apps) ship all their code — UI logic, buttons, layouts, everything — bundled inside the `.app` file on your Mac. Electron apps like VS Code work the same way: their UI code lives in `Resources/app.asar`. You can unpack it, find the JavaScript that draws the sidebar, edit it, repack.

## What Claude Code actually is

Claude Code (the app you're using) is an **Electron shell that loads its UI live from Anthropic's servers** — very close to just being a browser window pointed at claude.ai. The `.app` bundle contains:

- Window management (making the OS window appear)
- Authentication code
- MCP/file-system bridges (letting the UI talk to your disk)
- Auto-updater
- **NO UI code for panes, chat, files pane, layout, or anything you can see on screen**
