# Project Perception: AI Expo Hackathon Submission

## What It Built
Project Perception is "a video analysis platform designed for interrogation and surveillance scenarios" that leverages computer vision to analyze video content.

## Problem Solved
The platform addresses the need for automated analysis of human behavior in video by detecting emotions, eye blinks, and objects simultaneously, providing investigators and analysts with insights they might miss manually.

## Key Features
- Real-time emotion detection via webcam
- Automated video upload and analysis capabilities
- Object recognition using YOLOv8
- Video playback and historical review
- AI chatbot for querying results

## Technology Stack
The backend uses "Python 3.12, Flask, OpenCV, DeepFace, YOLOv8 (ultralytics), Torch, Pandas, NumPy, OpenAI API" with a frontend built on "HTML5, CSS3...Vanilla JavaScript, Font Awesome."
