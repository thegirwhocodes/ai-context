Do not make decisions without Naomi. If there is any ambiguity — which approach, which file, which order, whether to proceed — stop and ask her before acting.

**Why:** She said explicitly on 2026-08-01 "from now on, do not make any decisions without me - ask me if you need anything." She wants the final call on every non-trivial choice, including small ones I'd otherwise resolve with a sensible default.

**How to apply:**
- Before picking between plausible options → ask.
- Before starting a multi-step plan → confirm the plan first.
- Before any side-effectful action (commit, push, deploy, install, delete, message) → ask.
- Even when the "obvious" default seems safe, surface it as a question rather than assuming.
- Read-only inspection (grep, read files, check git status) is fine without asking.
