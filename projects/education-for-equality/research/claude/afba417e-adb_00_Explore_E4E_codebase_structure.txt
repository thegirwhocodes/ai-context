- Video + text lessons

### 2. SABI AI TUTOR SYSTEM

**Core Teaching Logic** (`lib/voice/sabi-shared.ts` / `sabi-server/llm.py`)

The `SABI_CORE_PROMPT` (~5,000 tokens) defines:
- **Personality**: Warm, encouraging, Nigerian English, uses child's name
- **Pedagogy**: NAIRA-FIRST principle — frame math as market scenarios before abstract math
- **Lesson Structure** (5-7 min):
  1. Greeting + Recall (30s)
  2. Today's Lesson (90s)
  3. Guided Practice (90s)
  4. Independent Check (60s)
  5. Wrap-up + Hook (30s)
- **Adaptive Behavior**:
  - 3+ correct → increase difficulty
  - 2+ wrong → scaffold with smaller numbers
  - Never repeat same question
- **Voice Expression**: Uses `[laugh]`, `[chuckle]`, `[sigh]` tags for emotion

**RAG Integration** (`lib/rag/retrieval.ts`)
- Curriculum chunks stored in pgvector (Supabase)
- Generates embedding via sentence-transformers
- Context injected per-call (~1,500-2,000 tokens)
- Reduces per-turn tokens from ~20,500 to ~6,500-10,500

### 3. VOICE INTERFACES

**Twilio Integration** (`app/api/sabi/voice/*`)
- Webhook at `/api/sabi/voice/incoming` — greeting + gather speech
- Webhook at `/api/sabi/voice/respond` — process speech → LLM → TTS
- TwiML responses with `<Gather>` for speech input
- Auto wrap-up after 12 exchanges or wrap-up patterns detected

**Africa's Talking Integration** (`voice.py`, `app/api/sabi/at/*`)
- Similar flow to Twilio but using AT's XML format
- Cost: ₦3/min incoming (free to callers on 2G)
- Fallback to YarnGPT TTS if primary fails

**Asterisk SIP** (Optional flash callback)
- Child receives instant callback (credit-free)
- Configured in `asterisk/extensions.conf`

## IMPORTANT ARCHITECTURAL DECISIONS

### 1. Naira-First Math (Market Scenarios)
- **Why**: Research shows children solve market-framed math 9x better than abstract
- **Implementation**: Every lesson starts with ₦-based scenario (groundnuts, pure water, bus fare)
- **Pattern**: Market scenario → intuitive solve → name the formal math → practice

### 2. Serverless Voice Handling on Vercel
- **Challenge**: Phone calls are stateful, Vercel functions are stateless
- **Solution**: Use Supabase `sabi_active_calls` table to persist call state
- **Benefit**: No server infrastructure for web voice — Vercel handles scaling

### 3. TTS Fallback Chain
- **Why**: Single TTS provider = downtime risk
- **Chain**: ElevenLabs (fastest) → Chatterbox (emotion-aware) → YarnGPT (free)
- **Tradeoff**: Adds ~1-2s latency but ensures reliability

### 4. RAG Over Full Curriculum in System Prompt
- **Before**: 20,500 tokens per turn (full curriculum + conversation)
- **After**: 6,500-10,500 tokens per turn (RAG chunks + conversation)
- **Benefit**: Lower latency, cheaper, faster responses

### 5. Emotion Tags for Voice
- **Tags**: `[laugh]`, `[chuckle]`, `[sigh]`, `[praise]`
- **Used by**: Chatterbox TTS to set exaggeration level (0.35-0.75)
- **Benefit**: Natural, expressive voice without re-training model
