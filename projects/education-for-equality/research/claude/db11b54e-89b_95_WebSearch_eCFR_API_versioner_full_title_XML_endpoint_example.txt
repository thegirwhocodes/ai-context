## eCFR API Versioner Full Title XML Endpoint

The eCFR API includes the following key endpoints:
- `https://www.ecfr.gov/api/versioner/v1/titles.json` - Retrieves title metadata
- `https://www.ecfr.gov/api/versioner/v1/full/{date}/title-{title_number}.xml` - Retrieves full XML content for a title

## Developer Resources

The base URL for all API endpoints is https://www.ecfr.gov, and a request to the eCFR titles endpoint returns three date fields per title—latest_amended_on, latest_issue_date, and up_to_date_as_of—as well as additional fields.

## GitHub Resources

Several GitHub repositories contain examples and tools for working with the eCFR API:
- The niemasd/eCFR-Analyzer-Case-Study repository demonstrates eCFR API integration and uses these endpoints for retrieving agency data, title metadata, and full XML content
- The Electronic CFR Bulk Data Repository resources are found at http://www.gpo.gov/fdsys/bulkdata/ECFR/resources

For the official eCFR API documentation, you can visit the eCFR API documentation page at https://www.ecfr.gov/developers/documentation/api/v1.
