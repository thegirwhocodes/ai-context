## What is KATube?

KATube is a tool to automate the process of creating datasets for training Text-To-Speech (TTS) and Speech-To-Text (STT) models. From a list of YouTube playlists or YouTube channels, KATube will generate dataset with audios and texts.

## How Audio-Subtitle Alignment Works

KATube downloads all audios with their respective subtitles, segments the audios, performing audio-text alignment using the external tool AENEAS. From this alignment, KATube will segment the audio, according to the sentences created.

## Playlist Processing

To use KATube with playlists:

1. Configure the file "input/playlists_id.txt" and check the settings in the "config.py" file.

## Data Quality Validation

KATube includes a validation step to ensure dataset quality. The external STT will generate a transcript of the segmented audio. So, you can compare the sentence with the transcript using the levenshtein distance, and thus have a guarantee that the audio really matches the text of the sentence.

## Related Tools

If you're looking for alternatives, there's also the `youtube_tts_data_generator` package. You create a YTSpeechDataGenerator instance, create a '.txt' file that contains a list of YouTube videos that contains speeches, and call generator.prepare_dataset('links.txt'), which will take care about creating your dataset, creating a metadata file and trimming silence from the audios.

For more detailed documentation and code examples, you can check the official GitHub repositories for both KATube and youtube_tts_data_generator.
