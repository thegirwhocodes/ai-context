## Key Resources Found:

### 1. **ST-GCN-SL Repository** (Direct Sign Language Implementation)
The ST-GCN-SL (Spatial Temporal Graph Convolutional Networks for Sign Language) repository provides pretrained weights that can be downloaded, and it appears to be available on GitHub at `amorim-cleison/st-gcn-sl`.

### 2. **SAM-SLR (Skeleton-Aware Multi-Modal Sign Language Recognition)**
The official SAM-SLR code won the CVPR 2021 Challenge on Large Scale Signer Independent Isolated Sign Language Recognition. The skeleton modality can be trained, finetuned and tested using code in the SL-GCN/ folder, with instructions to prepare skeleton data into four streams (joint, bone, joint_motion, bone motion). Pretrained models for all modalities are provided to reproduce submitted results, available at `jackyjsy/CVPR21Chal-SLR` on GitHub.

### 3. **Standard ST-GCN for Action Recognition**
The original ST-GCN repository provides pretrained model weights that can be downloaded by running a script, with models also available from GoogleDrive or BaiduYun.

### 4. **Working Pipeline Details**
The ST-GCN-SL model is the first to apply ST-GCN to sign language recognition, and the skeleton-based approaches use keypoint extraction from videos before feeding them into the graph convolutional networks.

These repositories should provide ready-to-use pretrained weights and inference code for skeleton keypoint-based sign language recognition using ST-GCN architectures.
