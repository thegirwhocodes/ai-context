## Primary Free Options

**Cloudflare Tunnel** is the top recommendation. Cloudflare Tunnel is completely free to use with no bandwidth limits or usage restrictions, with advanced features available through Cloudflare Zero Trust plans but basic tunneling functionality remaining free. Cloudflare Tunnel runs a lightweight daemon (cloudflared) in your infrastructure that establishes outbound connections between your origin web server and the Cloudflare global network.

## Other Notable Alternatives

Localtunnel is written in node and is a popular suggestion. Localtunnel is an open-source, self-hosted solution that aims to simplify hosting a local resource externally and is installable via npm.

Playit.gg offers a free tier with up to 4 TCP tunnels and 4 UDP tunnels, with the paid version costing $3 USD per month or $30 per year.

**Open-Source Options**: frp is the most popular open-source alternative with over 100,000 GitHub stars and supports HTTP/HTTPS, TCP, and UDP. mmar is a zero-dependency, self-hostable, cross-platform HTTP tunnel that exposes your localhost to the world on a public URL, released under AGPL-3.0 License and written in Go.

## Key Comparison
ngrok is a tunneling service that creates a secure, encrypted tunnel between a local machine and a public internet address, allowing you to expose a local web server to the internet and access it through a public URL. However, ngrok's free tier is more limited compared to these alternatives.
