### 3. FRUSTRATIONS & PAIN POINTS WITH THE DAVINCI-MCP APPROACH

**Pain Point 1: Subtitle API is Locked**
Resolve's subtitle API **doesn't support styling or text editing programmatically**. Claude kept hitting this wall:

> "SetName doesn't work on subtitle items. The auto-transcription has 26 segments with wrong lyrics, and we can't edit them via the API."

She had to manually style subtitles in the UI. This defeated the purpose of the "Claude does it" vision.

**Pain Point 2: Timing Misalignment**
Auto-transcription from Whisper kept getting the lyrics wrong (e.g., "I'll keep you on my mind I won't sacrifice you" instead of "King of all my life, I will sacrifice"). The Python caption script I wrote couldn't reliably sync to her soft "Oh"s against guitar.

> "the captions right now do not match the right timing"

**Pain Point 3: Fusion Composition Chaos**
Trying to create 40+ Text+ captions as overlays split the video into fragments and caused display glitches:

> "The Fusion comps all went to track 1, splitting up the original video clip. That's not good — they replaced parts of the video instead of overlaying."

**Pain Point 4: DaVinci Resolve Crashes Under Load**
When running heavy Fusion scripts, Resolve crashed:

> "quit unexpectedly"

The MCP connection had to be re-established, settings had to be reapplied.

**Pain Point 5: Color Grading API is Fragile**
Setting CDL values required **exact string formatting**, and color grades weren't applying consistently. The soft glow was amplifying red tints unpredictably:

> "How does it look — still red? If so, the Fusion comp (grain/glow/vignette) might be the issue. The SoftGlow adds a glow to highlights which could amplify any warm tint and make it look red."

### 4. AGENT-ARCHITECTURE RESEARCH (Session 6abf9016)

In the research session (April 20, 2026), Naomi asked me to do **deep research on how people build AI agents**. Five parallel agents were spawned to cover:

#### **Framework Recommendations:**

**Top Pick: Claude Agent SDK (TypeScript) + Vercel AI SDK**
- Use Claude Agent SDK in **Electron main process** as the agent brain
- Use **Vercel AI SDK** in renderer for the UI
- **Skip** LangGraph (too verbose), OpenAI Agents SDK (weaker filesystem/memory), CrewAI, AutoGen
- **MCP is the de-facto standard** — the existing DaVinci Resolve MCP slots right in

**Why Claude Agent SDK beats others:**
- Built explicitly for Claude (better prompt caching, tool use, structured outputs)
- Filesystem access by default (can read/write projects, manage memory)
- Memory management patterns native to the SDK

#### **"Alive" UX Patterns (Sana AI-Inspired):**

The research recommended stealing these patterns from Sana:
- **One-box chat** that auto-routes intent (user says "make captions," agent decides: transcribe → style → place)
- **Visible reasoning** — show Claude's thinking ("because this clip has a laugh at 0:14, I'll cut before it")
- **Background daemon** watching `~/Movies/Lumina Inbox/` for dropped files (file watcher → auto-import)
- **3 variations by default** (A Safe / B Stretch / C Wild) — user picks one, becomes training signal
- **Ambient sidebar** ("Lumina noticed you added a new clip…") instead of toasts/notifications
- **Pre-canned greeting bank** weighted by recency (Claude greets users like "Good afternoon, Naomi")

#### **Video Analysis Stack (SOTA):**

Don't rebuild Opus Clip. Use:
- **Gemini 2.5 Flash** for video understanding (scene detection, context)
- **WhisperX** for word-level transcription with timing
- **PySceneDetect** for automatic cut detection
- **Audio energy analysis** for finding vocal peaks

Surface the **features as a dashboard** (hook score, pacing %, face detection %, emotion peaks) rather than a fake "virality score."

**Skip Instagram API for MVP** — Naomi uploads on phone for v1. v2: Graph API with Instagram Login, long-lived tokens in macOS Keychain, Cloudflare R2 for uploads.

#### **Memory System (5-Tier Model):**

Single SQLite file + sqlite-vec extension + BGE-small-en-v1.5 embeddings (130MB local, no API calls):

1. **Short-term** — current session (style choices made today)
2. **Working** — active project (clip names, timeline structure)
3. **Episodic** — past projects (what she edited, when, outcomes)
4. **Semantic** — knowledge base (worship video aesthetics, brand colors, her voice)
5. **Procedural** — skills (how to export for TikTok, batch caption, color grade)

**Schema includes:**
- `user_profile` (faith, location, education, personality)
- `preferences` with supersedes chain (color palette, caption style, posting rhythm)
- `projects` (ID, name, clips, timeline structure)
- `edit_decisions` (she accepts/rejects variations → implicit training signal)
- `memory_items` + `memory_vecs` (vector embeddings for semantic search)

**Write policy:** Explicit triggers + Haiku salience-judge + behavioral events (when she accepts/rejects edits, store it).

**Read policy:** Always load ~800 tokens of core memory (brand, current project) + hybrid SQL-filter-then-vector-rank for context.

#### **Production Engineering Checklist:**

The research compiled a **10-item day-1 shipping checklist**:
1. Prompt caching for repeated system prompts
2. Streaming UI updates (show captions being placed in real-time)
3. Structured outputs for tool results
4. Cost ceiling ($3/session max)
5. Observability (Langfuse for token tracking, latency, failures)
6. Secrets in macOS Keychain (API keys, Resolve auth)
7. Electron packaging + signing
8. Privacy (all data local except Claude API calls)
9. Error recovery (graceful fallbacks when Resolve crashes)
10. Hotkey setup (Cmd+K to open agent, Cmd+Enter to apply edits)

## SUMMARY

**Naomi's vision is to build "Ed.it" — a personal AI video-editing agent that:**

1. **Understands her brand** (warm colors, worship aesthetic, authentic faith messaging)
2. **Watches her files** (file watcher → auto-import video clips)
3. **Generates variations** (3 caption/edit styles, she picks)
4. **Remembers her voice** (SQLite memory of past edits, brand preferences, her personality)
5. **Executes end-to-end** (transcribe → caption → style → place → export, no manual UI work)
6. **Feels alive** (visible reasoning, greetings, background suggestions like "you added a new clip")
7. **Handles worship video specifically** (subtle captions, warm color grade, lets music breathe)

**The frustration with DaVinci Resolve MCP** is that the subtitle API is locked behind the UI — she can't automate styling. The research pivoted to a **standalone Electron app** with Claude Agent SDK as the brain, avoiding Resolve's API limitations by using FFmpeg/Gemini/WhisperX for the hard work, and treating Resolve as just the final render engine (or optionally, a display-only reference).

The **Ed.it project** in the Social Media folder is the research foundation for this standalone agent — frameworks, tool design patterns, memory architecture, production engineering — all documented for building a purpose-built AI video editor tailored to Naomi's creative voice.
