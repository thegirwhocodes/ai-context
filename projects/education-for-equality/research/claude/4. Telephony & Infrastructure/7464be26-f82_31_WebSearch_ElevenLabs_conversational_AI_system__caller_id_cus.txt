## Dynamic Variables and System Variables

Dynamic variables allow you to inject runtime values into your agent's messages, system prompts, and tools, enabling you to personalize each conversation with user-specific data without creating multiple agents.

### System__caller_id and Related Variables

The system__caller_id variable represents the caller's phone number (for voice calls only), and is part of a set of system variables that also includes system__called_number (destination phone number), system__call_duration_secs (call duration in seconds), system__time (current time in specified timezone), system__timezone (user-provided timezone), and system__conversation_id (ElevenLabs' unique conversation identifier).

### Custom Variables Restriction

Custom dynamic variables cannot use the reserved system__ prefix.

## Dynamic Variables in System Prompts and Custom LLM

You can define runtime values using {{ var_name }} syntax to personalize your agent's messages, system prompts, and tools. This syntax allows you to incorporate dynamic variables directly into your system prompt configuration.

## Secret Dynamic Variables

Secret dynamic variables are indicated to ElevenAgents that these should only be used in dynamic variable headers and never sent to an LLM provider as part of an agent's system prompt or first message, and are recommended for auth tokens or private IDs that should not be sent to an LLM.
