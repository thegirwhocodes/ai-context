## Installation Steps

Click on Agent session and select the "..." dropdown at the top of the editor's side panel, then select MCP Servers where you will find the MCP Store.

To add a custom MCP server, select Manage MCP Servers at the top of the MCP store and then click on View raw config in the main tab.

## Configuration File Location

The mcp_config.json file is located at:
- Windows: C:\Users\<USERNAME>\.gemini\antigravity\mcp_config.json
- macOS/Linux: ~/.gemini/antigravity/mcp_config.json

## Configuration Settings

Modify the mcp_config.json with your custom MCP server configuration. 

For HTTP-based servers, Antigravity requires serverUrl for HTTP-based MCP servers (rather than "url" used in other tools).

A typical configuration structure includes the mcpServers object with server details such as command, args, and environment variables. Antigravity recommends keeping total enabled tools under 50 for optimal performance.

After making changes, close and reopen Antigravity for the changes to take effect.
