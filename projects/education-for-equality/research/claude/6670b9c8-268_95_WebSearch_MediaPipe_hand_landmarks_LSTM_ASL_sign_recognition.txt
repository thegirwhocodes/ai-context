## Key Research and Projects

SLRNet is a real-time system that recognizes dynamic hand gestures using MediaPipe Holistic landmark extraction and LSTM networks, processing live video streams via webcam to classify ASL letters and words. The code and dataset are available at https://github.com/Khushi-739/SLRNet

MP-GestLSTM is a lightweight LSTM-based model trained on a custom MP-Gest dataset comprising 800 videos across 20 ASL word-level classes, designed as a webcam-based system for real-time gesture classification.

Research has combined MediaPipe framework with RNN models including LSTM for dynamic sign language recognition, with GRU, LSTM, and Bi-directional LSTM provided for DSL recognition.

## GitHub Repositories

A GitHub project based on Google's MediaPipe Hands uses hand landmarks detected via BlazePalm Detector to extract 2-D or 3-D coordinates of hand positions.

The asl-landmark-classifier is a machine learning system for ASL alphabet recognition using MediaPipe hand landmarks (63D) and classical machine learning, with real-time recognition capabilities.

## Accuracy Results

Hand gesture recognition using LSTM has achieved 99% accuracy on 26 ASL alphabets. Other models achieved accuracy of more than 99% on dynamic sign language recognition tasks.
