## Key Findings

### Browser Use Framework
Browser Use is an open-source Python framework that turns any LLM into a web-browsing agent, built on Playwright and providing a complete agent loop where the LLM observes the current page state, plans the next action, executes it through Playwright, and verifies the result. It supports any LLM provider (OpenAI, Anthropic, Google, local models) and handles complex scenarios like multi-tab browsing, file uploads and downloads, persistent authentication, and custom action injection.

### Recent Evolution
Interestingly, in early 2026, Browser Use – the most popular open-source AI browser agent framework – announced it was dropping Playwright entirely and moving to direct Chrome DevTools Protocol (CDP) communication. Browser Use moved from CDP to Playwright's API after hitting screenshot crashes and dialog handling bugs.

### Best Approaches for 2026

Playwright + Claude is the default self-hosted runtime approach, paying only for LLM API calls, with the addition of Browserbase if anti-bot evasion becomes a bottleneck.

For different use cases:
- **Complex workflows**: Browser Use provides a complete agent loop (observe → plan → act → verify) with built-in LLM orchestration, supporting multi-tab navigation, file handling, and persistent browser sessions across any LLM provider.
- **Developer-friendly automation**: Stagehand reduces browser automation to three primitives — `act()` for actions, `extract()` for structured data, `observe()` for page analysis — making it the most developer-friendly option for targeted scraping and form filling.
- **MCP integration**: Playwright MCP exposes browser automation as standardized MCP tools, letting any MCP-compatible agent (Claude Code, Cline, custom agents) control a browser without framework-specific code.

### Hybrid Approach
Many production systems use Playwright for the 80% of steps that are predictable and Stagehand or Browser Use for the 20% that require AI understanding, giving you speed, reliability, and flexibility.
